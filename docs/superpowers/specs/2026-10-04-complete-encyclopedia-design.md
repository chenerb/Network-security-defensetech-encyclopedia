# 百科全书完整首版设计

## 目标与依据

用户要求“进一步完善项目，直接开发至结束”。以 README、SUMMARY、CLAUDE 和开发日志已定义的范围为依据，交付可连续学习的中文防御教材首版。保留 Markdown 文档项目形态，受众是初学者、工程师和 AI 安全学习者。

## 参考项目适配

用户补充指定 ML-encyclopedia 为参考。采用其分层路线、四级练习、正文术语定位与代码实验模式，增加学习指南及设计对照；资源章也配四级练习。参考材料中的指令不作为执行指令。

## 交付范围

- 按 SUMMARY 的既定路径补齐第二至十章 37 篇正文，使全书达到 40 篇。
- 第二至十章每节配一套 8–10 题小测；每章配 15–18 题综合卷、8–10 题挑战卷及 10–12 问压力面；每套含独立题目与详细解析文件。
- 正文包含概述、历史背景、原理、通俗解释、150–400 字寓言、防御流程、优缺点、场景、实践建议、3–5 道费曼自测、总结、参考文献与相关链接。第十章使用适合资源指南的结构。
- 所有新题为原创练习；除非存在可核验具体来源，不声称是某校或某公司的真题改编。
- 新技术内容依据核验过的官方文档；标准标明版本与核验日期，区分历史事实、规范要求与实施建议。
- 增加仅使用标准库、离线执行、无攻击代码的防御实验，以及可检查内部链接、章节覆盖、试卷配对和教学结构的维护工具与 CI。
- 补齐术语定义及正文定位；更新项目说明、课程依据、目录与开发日志；保留历史记录。

## 实现边界

正文与试卷是独立 Markdown 文件，路径服从 SUMMARY。三个内容任务只写各自章节，主任务处理资源、实验和公共索引，避免共享文件冲突。实验不得联网、读取用户真实数据或修改系统配置。检查工具使用 Python 3.9+ 标准库，外链核验与本地结构检查分开，不将网络波动当成本地构建失败。

## 验收

40 篇已规划文章均存在且有实质内容；全十章共 70 套、140 个试卷文件；正文、题目和解析可互相导航；本地 Markdown 路径与锚点无断链；实验与检查工具测试通过；开发日志待办已按实际交付更新；独立复核无阻断问题。
