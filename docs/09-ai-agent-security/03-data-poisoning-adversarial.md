# 数据投毒与对抗攻击

## 概述

答案变错了，是模型学坏了，还是查阅的资料被改了？数据投毒（Data Poisoning）与对抗攻击（Adversarial Attack）都针对 AI 完整性，但发生阶段不同，决定调查与修复的位置。

> 本节仅用于教育学习与合法防御，不提供样本构造、触发器或利用代码。

## 历史背景

机器学习研究长期关注输入扰动、训练数据完整性与模型隐私。NIST 的 [AI 100-2 E2025](https://csrc.nist.gov/pubs/ai/100/2/e2025/final) 于 2025 年发布对抗机器学习术语与缓解分类；[OWASP LLM04:2025](https://genai.owasp.org/llmrisk/llm042025-data-and-model-poisoning/) 则面向 LLM 生命周期的预训练、微调与嵌入数据风险。术语范围要说明：传统训练投毒与检索知识库污染并非同一技术过程。

## 核心原理

| 类型 | 改变的对象 | 是否通常改模型权重 | 主要修复对象 |
|---|---|---|---|
| 训练数据投毒 | 预训练或微调样本、标签 | 通过训练可能改变 | 数据批次、训练产物 |
| 模型投毒 | 参数、训练流程或分发制品 | 是，或改变训练结果 | 模型制品、构建与发布链 |
| RAG 知识库污染 | 文档、索引、元数据或排序 | 通常不改变 | 原文、索引、缓存及权限 |
| 推理期规避（Evasion） | 当前输入及可控条件 | 通常不改变 | 输入校验、鲁棒性与业务复核 |

一次外部文本进入当前上下文，不代表它已经训练进模型。若知识库被污染，删掉一份文档仍可能留下向量、缓存、副本和已生成报告；若训练受影响，仅清理检索库不能消除参数里的影响。

后门（Backdoor）可能让大多数样本正常，仅特定条件下异常，因此平均准确率不足以证明清洁。对抗鲁棒性（Adversarial Robustness）需要指定输入范围、攻击者能力与预算；“加了噪声仍正确”不等于防住所有对抗变化。

隐私攻击还需另行评估：**模型逆向（Model Inversion）**可能从模型信息推断训练数据相关特征或重建类别代表，不等于必然恢复某条原始记录；**成员推断**则判断一个样本是否参与训练。NIST AI 100-2 E2025 第 2.4 节区分这些目标。防御应约束模型访问、输出信息与查询预算，评估数据泄漏，并结合[隐私保护](../07-data-security-privacy/03-privacy-preserving.md)明确保证和假设；不能把模型准确率当隐私指标。

> 🧠 **费曼自问**：教科书被改和考试当天题纸被改，为什么需要不同补救？

## 通俗解释

训练像学习食谱，模型制品像厨师记住的做法，RAG 像临时查菜谱架，推理输入像当天食材。查错菜谱不一定说明厨师记忆被改；排查必须找到受污染的环节。

## 📖 寓言故事

烘焙学校收到三种投诉：毕业生一直记错用量，店员只在查阅新手册时出错，还有一批外形正常的食材让称重器读数异常。校长原想统一换手册，老师却把三条流程画出来。第一组要追查教学材料和训练批次；第二组要移除错误手册，并更新架上目录与抄录副本；第三组要核验当天食材和测量条件。他们给每批资料留下供应者、版本和签收记录，再用独立样例检查修复。错误结果相似，污染位置却不同；找准阶段比统一喊“模型不可靠”更能解决问题。

## 防御步骤 / 工作流程

1. 为数据、标签、模型和索引建立来源与版本账本，限制修改者，审核外部供应商和关键变更。
2. 验证制品校验值、签名和预期来源，使用安全加载方式与隔离环境；校验匹配仅证明对应制品未变，不证明原制品良性。
3. 清洗和复核数据异常，检查重复、来源集中、标签偏移与敏感信息；独立划分训练、验证和保留测试集，防止数据泄漏。
4. 对知识库审核文档、权限元数据与索引构建；按用户和租户过滤检索，同时验证内容真实性与引用支持度。
5. 按明确威胁模型评估特定条件和正常任务，记录分群结果；漂移是线索，不自动证明恶意投毒。
6. 发现问题后冻结受影响版本，沿血缘找到传播范围，恢复可信数据与制品，重建索引并清缓存；必要时重新训练，再独立验证。

## 优缺点分析

### 优点

来源追踪和版本化便于定位与回滚，独立评估可发现平均指标掩盖的异常。

### 缺点

审查全部数据成本高，异常检测可能漏掉精心混入的样本。鲁棒性措施也可能降低正常任务表现；外部模型的完整训练来源可能不可见。

## 应用场景

供应商模型引入、用户反馈自动用于微调、多人维护的企业知识库、视觉识别服务，都需要根据各自阶段布置控制。

## 实践建议

用三份合成文档练习血缘追踪：哪份被审核、哪版索引包含它、哪些回答引用它。不要把“向量不易读”当加密，也不要把独立测试集重新加入训练后仍称为独立验证。

## 🧠 费曼自测

1. 训练投毒和 RAG 污染怎样影响模型？
2. 为什么签名正确的制品仍可能不安全？
3. 移除污染原文后还需检查哪些派生数据？
4. 平均准确率为什么可能漏掉后门条件？

## 总结

按生命周期区分污染，按血缘追踪影响，按独立样例验证恢复。控制完整性和权限必须覆盖原文、参数、索引与缓存。
