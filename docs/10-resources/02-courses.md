# 在线课程：用作业检验你是否真的懂了

## 概述

视频看懂了，为什么白纸上还画不出一次安全登录？课程的价值在于连贯的概念和反馈。本节选择可以核验的官方入口，把学习落实到自己的解释、设计和复盘。

## 学习安排

零基础读者先读本项目前三章，挑一门系统课程作为主线。工程师可先读权限、浏览器边界和软件开发部分，再补密码学。关注 Agent 的读者先学习认证、隔离与 Web 权限，再进入第九章；“会调 API”不能代替理解授权。

建议每周用三次短学习：第一次看讲义并列五个新概念；第二次关掉材料复述数据流；第三次做本项目对应小测并写一页复盘。课时按自己的前置基础调整，不能以看完视频数量充当掌握程度。

## 📖 寓言故事

阿文跟着老师看航海视频，觉得每一次转舵都很容易。出门前，老师给他一张空白海图，要他标出暗礁、风向和避险港口。他只记得操作动作，却说不出何时该用。重新看视频时，他开始记录每个动作的条件。再画海图，他终于能解释为什么某条航线更安全。安全课程中的作业就是这张海图：迫使你把理解变成可检查的判断。

## 实践建议与取舍

- 作业涉及攻防时，只在课程明确允许的隔离环境学习；本项目以防御设计和合成数据实验为主。
- 给每次作业写威胁模型和修复建议，即使课程只要求解释一个现象。
- 老课程中的协议版本、浏览器行为和编译选项可能已变，结合当前官方规范核验。
- 选择一门课程完整学习，比同时订阅许多不相连的片段更容易发现知识缺口；补充课程用于解决明确的问题。

## 🧠 费曼自测

1. 如何判断自己掌握了一个权限模型，而不是记住了术语？
2. 学习历史归档课程时，哪些建议需要检查时效？
3. 如果一份答案只列安全产品，没有资产与验证步骤，你会怎样补全？
