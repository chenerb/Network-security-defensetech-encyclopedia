# 配套试卷导航

全十章共 70 套练习，每套含独立题目与详细解析，共 140 个试卷文件。内容为原创概念题和模拟岗位场景，不声明来自未核验的高校或企业真题。

## 使用方法

1. 学完一节先做题目版，再读解析；小测建议 20–30 分钟。
2. 读懂每个选项的理由，给场景题按分项证据评分，不只检查最后结论。
3. 用解析的考点分布表定位弱项，回到正文重新画流程、完成费曼自测。
4. 章末综合卷建议 60–90 分钟；挑战卷检验假设与边界；压力面练习回答、追问与踩坑点。
5. 资源章也有配套题，练习选书、读规范与论文、判断实验范围和证据强度。

| 级别 | 题量 | 学习用途 |
|---|---|---|
| 节末小测 | 8–10 | 概念辨析、简答与场景应用 |
| 章节综合卷 | 15–18 | 串联全章原理与防御设计 |
| 挑战卷 | 8–10 | 复杂边界、推导与方案取舍 |
| 压力面 | 10–12 | 模拟岗位表达、追问与复盘 |

分数帮助定位缺口，不是职业认证。每份题目以自己的评分说明为准；开放题接受满足目标、假设和验证条件的等价方案。建议搭配[学习指南](../LEARNING_GUIDE.md)与[离线实验](../examples/README.md)。
