## 答案与解析

### 1. 纵深防御核心（选择题，8 分）

**正确答案：B。**

**逐项解析：**

- **A（错误）**：单点失效会留下缺口，强度不自动覆盖全部路径。
- **B（正确）**：层之间承担互补作用，需验证其共同依赖与效果，并非预测所有系统必定失守。
- **C（错误）**：内部身份、主机、应用和数据路径也需控制。
- **D（错误）**：外包分工不消除业务责任，需要明确授权与服务证据。

**易错点：**“假设可能失效”被说成任何单点一定失败或一定全面失陷。

**评分：**选对得 8 分，错选或不选得 0 分。

### 2. 教学分层（选择题，8 分）

**正确答案：A。**

**逐项解析：**

- **A（正确）**：这是本书的教学分组，并非唯一强制架构。
- **B（错误）**：是另一种部件分类，未对应本题采用的层次。
- **C（错误）**：是控制功能分类，可跨多层，但不是本题分组。
- **D（错误）**：是应用结构划分，未覆盖本书的物理与网络层。

**易错点：**把其他合理分类判为普遍错误，或把四层当国际强制标准。

**评分：**选对得 8 分，错选或不选得 0 分。

### 3. 多样化与共同失效（选择题，8 分）

**正确答案：B。**

**逐项解析：**

- **A（错误）**：多样化可能增加成本，不能保证便宜。
- **B（正确）**：不同机制与隔离的管理边界可降低相关失败，但必须检验实际共享依赖。
- **C（错误）**：外观并非防御目标。
- **D（错误）**：不同品牌可能共用库、凭据、供应商或规则，不能据此保证独立。

**易错点：**同品牌必同失效、不同品牌必独立，两种断言都没有充分证据。

**评分：**选对得 8 分，错选或不选得 0 分。

### 4. 零信任资源访问（选择题，8 分）

**正确答案：B。**

**逐项解析：**

- **A（错误）**：防火墙和内部隔离仍可支持架构。
- **B（正确）**：真实身份、设备和上下文参与有限权限决策，网络位置不是自动许可。
- **C（错误）**：加密不能替代认证与授权。
- **D（错误）**：资源访问决策与多层控制可组合，并非单一产品。

**易错点：**误把零信任或纵深防御等同一种产品，或说所有旧架构都默认内部可信。

**评分：**选对得 8 分，错选或不选得 0 分。

### 5. Assume Breach（选择题，8 分）

**正确答案：B。**

**逐项解析：**

- **A（错误）**：这是无条件乐观假设，未准备失效应对。
- **B（正确）**：是设计策略，不是每个系统必定被攻破的预言。
- **C（错误）**：应调查、恢复和改进，而不是放弃。
- **D（错误）**：预防与失效后的措施相互补充。

**易错点：**把假设可能失守理解成所有事故必然，或取消预防。

**评分：**选对得 8 分，错选或不选得 0 分。

### 6. 纵深误区与备份边界（选择题，8 分）

**正确答案：A。**

**逐项解析：**

- **A（正确）**：只堆产品忽略控制用途、身份、共同依赖和响应，不能构成可靠纵深。
- **B（错误）**：减少暴露和权限、隔离与检测可在部分新路径下发挥作用，限定结论才准确。
- **C（错误）**：成本、运维和误伤都需考虑。
- **D（错误）**：备份只解决部分恢复问题，访问与泄露处理仍需其他控制。

**易错点：**把“能降低后果”夸大成防住所有未知攻击，或备份能撤回泄露。

**评分：**选对得 8 分，错选或不选得 0 分。

### 7. 防火墙作用范围（判断题，8 分）

**正确答案 / 参考要点：**

错误。

**解析：**防火墙可限制允许的网络流量，但不能单独验证所有应用授权、账号行为、终端状态、物理访问和恢复。需依据场景组合并验证控制。

**易错点 / 踩坑点：**把边界存在当所有路径已有控制；或说防火墙对任何应用威胁都毫无帮助。

**评分依据（8 分）：**判断4分；作用与局限2分；组合验证2分。 等价且符合情境的防御方案可得分；仅罗列产品、没有解释作用位置不计对应分。

### 8. 零信任与纵深互补（判断题，8 分）

**正确答案 / 参考要点：**

正确。

**解析：**零信任强调资源访问的身份、条件与有限授权；纵深防御强调多道互补控制与失效处理。两者可共同采用，不因都包含验证就等价。

**易错点 / 踩坑点：**把两者一概对立，或将名称相似当同一架构。

**评分依据（8 分）：**判断4分；各自关注点各1分；互补与区别2分。 等价且符合情境的防御方案可得分；仅罗列产品、没有解释作用位置不计对应分。

### 9. 四层控制与验证（简答题，18 分）

**正确答案 / 参考要点：**

物理：机房门禁限制非授权接触，验证访客与交接记录；网络：分段及流量规则限制可达范围，检查允许与拒绝路径；主机：系统最小权限和补丁减少影响，验证身份与配置；应用/数据：按对象授权、正确输出处理、加密与审计保护数据，测试正常及越权请求。

**解析：**各层措施应服务威胁和资产，同一机制也可能跨层；分类用于讲解而非强制标准。

**易错点 / 踩坑点：**仅列产品名称，或以一个正常请求证明所有边界。

**评分依据（18 分）：**四层名称各1分，共4分；各层措施与作用各3分，共12分；至少一个具体验证与分类边界2分。 等价且符合情境的防御方案可得分；仅罗列产品、没有解释作用位置不计对应分。

### 10. 网店多层方案（场景题，18 分）

**正确答案 / 参考要点：**

1. 先识别客户资料、订单、支付依赖、身份和服务，评估泄露、改订单与停机路径，按后果排优先级。
2. 网络层限制管理入口与数据库可达路径，分段；大流量风险联动上游容量与清洗。主机层加固、最小权限、补丁与端点检测，验证关键配置和事件。
3. 应用层用服务端认证、按对象授权、参数化查询和适当输出处理，TLS保护传输；用合成正常、跨用户和异常输入用例验证。
4. 数据层按分类控制读取、加密与审计，备份与管理身份隔离并演练恢复；备份不追回泄露。
5. 检查共享凭据、代码与管理平台等共同依赖，设置日志、响应责任和回滚，验证一道失效后其他控制如何限制后果。

**解析：**示例以网络、主机、应用、数据组成四道控制，可补物理与流程。要检查功能、权限和依赖，而非仅换品牌。

**易错点 / 踩坑点：**认为不同品牌天然独立；加备份便解决所有CIA；测试未经授权第三方支付。

**评分依据（18 分）：**资产及优先级2分；四层措施与作用各3分，共12分；共同失效与授权验证2分；恢复和监控责任2分。 等价且符合情境的防御方案可得分；仅罗列产品、没有解释作用位置不计对应分。
