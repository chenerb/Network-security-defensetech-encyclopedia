## 答案与解析

### 1. 英文术语与范围（选择题，5 分）

**正确答案：C。**

**逐项解析：**

- **A（错误）**：中文使用可能有重叠，但英文范围与采用定义并不总相同。
- **B（错误）**：机构与标准定义有差异，跨语境绝对包含结论不可靠，也不应反过来断言任何包含都错误。
- **C（正确）**：明确对象、载体与语境可避免网络安全一词的歧义。
- **D（错误）**：信息、系统、网络与通信相互依赖，实践会重叠。

**易错点：**将Cybersecurity缩成网络基础设施，或无条件判定三者关系。

**评分：**选对得 5 分，错选或不选得 0 分。

### 2. 早期互联网蠕虫历史（选择题，5 分）

**正确答案：B。**

**逐项解析：**

- **A（错误）**：蠕虫事件不是防火墙技术。
- **B（正确）**：该事件后SEI建立的响应能力推动协调处置；只能说重要早期节点，不应说所有安全意识由此首次出现。
- **C（错误）**：CIA的形成是另一个历史问题，本事件不支持此归因。
- **D（错误）**：Enigma是更早的密码学历史，与该蠕虫事件不同。

**易错点：**将历史意义夸大为首个病毒、首个蠕虫或首次安全意识。

**评分：**选对得 5 分，错选或不选得 0 分。

### 3. 可用性定义（选择题，5 分）

**正确答案：C。**

**逐项解析：**

- **A（错误）**：机密性关注非授权披露。
- **B（错误）**：完整性关注合适的数据与状态变更。
- **C（正确）**：可用性关注预期时机和条件下功能可被使用。
- **D（错误）**：真实性关注身份或来源可信。

**易错点：**授权用户可用不意味着所有访客都应能访问。

**评分：**选对得 5 分，错选或不选得 0 分。

### 4. 未授权读取（选择题，5 分）

**正确答案：A。**

**逐项解析：**

- **A（正确）**：邮件被不应知悉者读取，直接损害机密性。
- **B（错误）**：题干没有修改或破坏邮件的事实。
- **C（错误）**：题干没有服务不可用的事实。
- **D（错误）**：行为归因证据是另一个问题，题干并未说明。

**易错点：**根据攻击者可能做什么推断题干没给出的结果。

**评分：**选对得 5 分，错选或不选得 0 分。

### 5. STRIDE信息泄露（选择题，5 分）

**正确答案：B。**

**逐项解析：**

- **A（错误）**：篡改主要对应完整性。
- **B（正确）**：未经授权的信息披露主要对应机密性。
- **C（错误）**：拒绝服务主要对应可用性。
- **D（错误）**：假冒主要针对认证/真实性，不同于信息披露本身。

**易错点：**威胁类别与最终属性可有多个映射，但应先判断具体事实。

**评分：**选对得 5 分，错选或不选得 0 分。

### 6. 风险与评估输入（选择题，5 分）

**正确答案：A。**

**逐项解析：**

- **A（正确）**：弱点、潜在有害事件、业务后果与已有控制共同支持风险判断。
- **B（错误）**：不存在未定义尺度下这样的通用数值公式。
- **C（错误）**：同样没有通用精确相乘关系，威胁也不只指攻击者。
- **D（错误）**：不同概念回答不同问题，混用会丢失控制位置。

**易错点：**把口诀写成精确概率公式，或忽略自然与意外威胁。

**评分：**选对得 5 分，错选或不选得 0 分。

### 7. 多层与相关失效（选择题，5 分）

**正确答案：B。**

**逐项解析：**

- **A（错误）**：多样化可能提高管理成本，需要收益权衡。
- **B（正确）**：功能、隔离和管理边界不同有助容错，需检验代码、身份、供应链等共同依赖。
- **C（错误）**：合规材料不是控制实际效果本身。
- **D（错误）**：品牌差异不保证失败独立，数量不是目标。

**易错点：**不同厂商等同独立，或多层必定能阻止任何攻击。

**评分：**选对得 5 分，错选或不选得 0 分。

### 8. 零信任的许可依据（选择题，5 分）

**正确答案：B。**

**逐项解析：**

- **A（错误）**：位置不证明身份与最小权限。
- **B（正确）**：按资源和真实条件作有限许可，与隔离、监测等控制互补。
- **C（错误）**：加密是重要支持手段，零信任不排斥。
- **D（错误）**：防火墙不能替代所有身份和对象策略。

**易错点：**把零信任当产品名，或以地理位置替代授权。

**评分：**选对得 5 分，错选或不选得 0 分。

### 9. 安全保证的前提（选择题，5 分）

**正确答案：B。**

**逐项解析：**

- **A（错误）**：密码学不能自动补授权、终端或流程缺陷。
- **B（正确）**：工程、密码学和形式化都能在明确条件下给有意义保证，开放环境需持续核验。
- **C（错误）**：离线有物理、介质、人员与供应链风险。
- **D（错误）**：运行条件和威胁会变，监控仍有作用。

**易错点：**将相对安全解释成没有任何可证明保证，或不对称已经数学证明安全不可能。

**评分：**选对得 5 分，错选或不选得 0 分。

### 10. 本书实施支柱（选择题，5 分）

**正确答案：D。**

**逐项解析：**

- **A（错误）**：技术是本题分类之一。
- **B（错误）**：人员承担设计、执行和判断职责。
- **C（错误）**：流程组织授权、响应和验证。
- **D（正确）**：预算是实施条件，但不在这三个分类标签中，不代表钱不重要。

**易错点：**CIA是目标，三大支柱是实施角度；分类不否认其他资源的价值。

**评分：**选对得 5 分，错选或不选得 0 分。

### 11. CIA约束与权衡（判断题，4 分）

**正确答案 / 参考要点：**

错误。

**解析：**访问、密钥、资源和恢复约束可能带来权衡；通过冗余和设计可改善，但需要验证具体环境，不能说加密必定损害可用性。

**易错点 / 踩坑点：**从存在取舍推出安全目标无法共同改善。

**评分依据（4 分）：**判断2分；具体条件和验证2分。 等价且符合情境的防御方案可得分；仅罗列产品、没有解释作用位置不计对应分。

### 12. 多路径降低风险（判断题，4 分）

**正确答案 / 参考要点：**

错误。

**解析：**还可缩小暴露、控制身份和权限、隔离、检测与恢复。备份减少部分停机损害，保险分担部分财务后果，两者不能追回泄露。

**易错点 / 踩坑点：**将降低影响的措施当阻止所有事故。

**评分依据（4 分）：**判断2分；至少两种其他路径及其边界2分。 等价且符合情境的防御方案可得分；仅罗列产品、没有解释作用位置不计对应分。

### 13. 学习防御的合法边界（判断题，4 分）

**正确答案 / 参考要点：**

正确。

**解析：**教育目的支持理解，不自动给予真实系统测试权，应采用合成数据或明确授权环境。

**易错点 / 踩坑点：**只强调目的善意而忽略范围。

**评分依据（4 分）：**判断2分；防御用途和授权说明2分。 等价且符合情境的防御方案可得分；仅罗列产品、没有解释作用位置不计对应分。

### 14. 防火墙不是全能控制（判断题，4 分）

**正确答案 / 参考要点：**

正确。

**解析：**功能范围不同，需要多层互补和端到端验证。防火墙也可能支持内部隔离，不应把它一概描述为只在公网边界。

**易错点 / 踩坑点：**认为防火墙只能部署外网，或已部署等于所有攻击都能防住。

**评分依据（4 分）：**判断2分；作用与需要其他验证2分。 等价且符合情境的防御方案可得分；仅罗列产品、没有解释作用位置不计对应分。

### 15. 假设失守的设计意义（判断题，4 分）

**正确答案 / 参考要点：**

正确。

**解析：**这是对失效后果的设计前提，可与预防结合，并持续用演练验证。

**易错点 / 踩坑点：**把设计假设当确定事件，或借此省掉预防。

**评分依据（4 分）：**判断2分；前提与预防互补2分。 等价且符合情境的防御方案可得分；仅罗列产品、没有解释作用位置不计对应分。

### 16. 锁的保证与业务目标（简答题，10 分）

**正确答案 / 参考要点：**

锁的效果需说明敌手能力、工具、时间、门框和钥匙保管。明确这些前提可给出有意义保证，环境变化需重评；攻防不对称只说明防御压力。防御按资产和后果减少暴露、限定权限、提高部分攻击成本，配合隔离、检测与恢复，把剩余风险交有权者决策。

**解析：**不能从寓言推出所有数学模型都不安全。成本也不是唯一目标，可信控制和损害减少同样重要。

**易错点 / 踩坑点：**将形式化/密码学保证全部否定，或保证对手无利就必然放弃。

**评分依据（10 分）：**模型与假设3分；变化及不对称边界3分；防御与剩余风险目标4分。 等价且符合情境的防御方案可得分；仅罗列产品、没有解释作用位置不计对应分。

### 17. 四层分组及作用（简答题，10 分）

**正确答案 / 参考要点：**

物理层：门禁限制非授权接触；网络层：分段和规则限制可达路径；主机层：加固、补丁和最小权限限制执行与影响；应用/数据层：正确授权、安全编码、传输/存储保护与审计。每项需正常和拒绝用例或运行证据验证，分类不是唯一强制标准。

**解析：**机制可能跨层，评价应看控制是否有效及依赖关系，不只标签。

**易错点 / 踩坑点：**将产品名当作用，或品牌数当独立性。

**评分依据（10 分）：**四层和对应作用各2分，共8分；验证及分类边界2分。 等价且符合情境的防御方案可得分；仅罗列产品、没有解释作用位置不计对应分。

### 18. 在线教育平台设计（场景题，10 分）

**正确答案 / 参考要点：**

1. 资产包括学生资料、成绩、视频、账号和服务。身份资料关注机密性及完整性，成绩还需可靠审计，视频与上课服务重视可用性；具体优先级应按业务与适用要求确认，不能承诺永不宕机。
2. Spoofing：冒用教师或管理员；Tampering：改成绩；Information Disclosure：跨用户读取身份资料；DoS：无法上课；可补Repudiation行为证据与Elevation of Privilege授权失效。
3. 网络层分段限制数据服务可达性并准备容量保护；主机层加固与补丁；应用层强认证、按对象授权、参数化查询、TLS与适当输出处理；数据层最小读取、加密、审计与隔离备份。
4. 检查共同凭据及管理平台，授权用合成身份测试正常、跨用户和跨租户路径；验证拒绝与日志、备份恢复和事件升级。备份不追回泄露，监控不代替预防。

**解析：**威胁与控制要对应具体数据流，评分看作用和证据。网络位置、密码正确或前端按钮都不能替服务端对象授权。

**易错点 / 踩坑点：**一堆产品没有边界；写“机密性极高”却不控制读取；未经授权测试第三方。

**评分依据（10 分）：**资产与CIA需求2分；至少四类威胁和属性2分；四道不同层控制及作用4分；共同依赖和具体验证2分。 等价且符合情境的防御方案可得分；仅罗列产品、没有解释作用位置不计对应分。
