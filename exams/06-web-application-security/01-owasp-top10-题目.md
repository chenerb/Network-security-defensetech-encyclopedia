- **B.** 任何年份都相同
- **C.** 2025，并明确核验日期

**题型**：选择题；**分值**：6 分。

- **A.** 常见关键风险的认知与沟通文档
- **B.** 应用无漏洞认证
- **C.** 完整且永不变的测试清单
- **D.** 只有扫描器需要学习

### 3. 2025 版中 A03 关注什么？

**题型**：选择题；**分值**：6 分。

- **A.** SQL 专用防火墙
- **B.** 软件供应链失败
- **C.** 口令长度
- **D.** 只关注页面布局

### 4. 退款流程在依赖服务超时后仍默认批准，最应检查什么？

**题型**：选择题；**分值**：6 分。

- **A.** 只换网页字体
- **B.** 只改数据库端口
- **C.** 仅加传输加密
- **D.** 异常处理是否安全失败并保持事务一致性

### 5. 某业务的低排名风险一旦发生会影响所有租户，应如何排序？

**题型**：选择题；**分值**：6 分。

- **A.** 按榜单原序忽略本地影响
- **B.** 结合资产、暴露、条件和现有控制重新评估
- **C.** 先买最贵工具
- **D.** 只修扫描器识别的项
