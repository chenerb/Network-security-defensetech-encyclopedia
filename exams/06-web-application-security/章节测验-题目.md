# 第六章 · 章节综合卷（题目）

> **原创说明**：本卷为本项目原创练习，模拟课程考核与安全岗位追问，不声称改编自具体高校或公司的真实试题。仅用于教育学习和授权防御。

共 15 道主问题，满分 100 分。选择题为单选；简答和场景允许等价防御方案，但须说明边界、步骤与验证证据。

### 1. 2025 Top 10 中“异常条件处理不当”提醒团队检查什么？

**题型**：选择题；**分值**：4 分。

- **A.** 只检查首页加载
- **B.** 故障、超时、回滚与资源耗尽后的安全行为
- **C.** 停用错误日志
- **D.** 失败时默认提权

### 2. 下列哪组边界对应正确？

**题型**：选择题；**分值**：4 分。

- **A.** SQL 参数绑定—数据与语法；XSS 输出处理—内容与代码
- **B.** SQL 参数绑定—所有业务授权
- **C.** CSP—介质清理
- **D.** CSRF 令牌—内存生命周期

### 3. 一个后台接口只依赖隐藏按钮限制管理员功能，问题是？

**题型**：选择题；**分值**：4 分。

- **A.** 按钮颜色不够明显
- **B.** 需要更长 URL
- **C.** 服务端授权缺失
- **D.** 只要登录就无风险

### 4. HTML 正文中的安全编码可直接用于所有 URL 和脚本上下文吗？

**题型**：选择题；**分值**：4 分。

- **A.** 完全可以
- **B.** 只要多编码一次
- **C.** 只要 HTTPS
- **D.** 不可以，应匹配上下文并避开危险位置

### 5. 应用采用 Cookie 会话且用 POST 修改地址，仍要考虑？

**题型**：选择题；**分值**：4 分。

- **A.** POST 自动证明意图
- **B.** CSRF 令牌、来源和业务授权
- **C.** 关闭全部脚本即可
- **D.** 数据库加密即足够

### 6. 依赖版本已写进 SBOM，下一步仍应？

**题型**：选择题；**分值**：4 分。

- **A.** 忽略漏洞公告
- **B.** 公开构建凭据
- **C.** 只核验界面
- **D.** 核验来源、更新决策、构建身份与修复流程

### 7. WAF 部署后，参数拼接查询仍存在，合理做法是？

**题型**：选择题；**分值**：4 分。

- **A.** 继续修复查询边界，并把 WAF 作为额外缓解
- **B.** 取消修复
- **C.** 给数据库更高权限
- **D.** 关闭错误监控

### 8. 安全扫描无高危报告能证明什么？

**题型**：选择题；**分值**：4 分。

- **A.** 全部设计安全
- **B.** 所有权限都正确
- **C.** 该工具在配置和覆盖范围内未报告高危
- **D.** 不需要人工评审

### 9. 区分输入验证、参数化、输出编码与授权。

**题型**：简答题；**分值**：8 分。

### 10. 为什么认证恢复和管理员后台应进入威胁模型？

**题型**：简答题；**分值**：8 分。

### 11. 同源 XSS 会怎样影响 CSRF 保护，整改顺序是什么？

**题型**：简答题；**分值**：8 分。

### 12. 怎样把一次事故转为 SDL 的长期改进？

**题型**：简答题；**分值**：8 分。

### 13. 场景：电商搜索使用原生 SQL 拼接，结果插入 HTML 字符串，数据库账号管理全实例。设计联合修复。

**题型**：场景分析题；**分值**：12 分。

### 14. 场景：退款接口授权服务超时后允许操作，用户可重复提交，日志仅写“失败”。设计安全需求与验收。

**题型**：场景分析题；**分值**：12 分。

### 15. 场景：100 次验证请求中 80 次应被拒绝、20 次应允许；系统拒绝了 75 次应拒绝请求和 3 次应允许请求。计算安全拒绝覆盖率与正常误拒率，并评价。
