# SQL 注入攻击与防御 · 节末小测（题目）

> **原创说明**：本卷为本项目原创练习，模拟课程考核与安全岗位追问，不声称改编自具体高校或公司的真实试题。仅用于教育学习和授权防御。

共 8 道主问题，满分 100 分。选择题为单选；简答和场景允许等价防御方案，但须说明边界、步骤与验证证据。

### 1. 参数化查询最直接保证什么？

**题型**：选择题；**分值**：6 分。

- **A.** 所有用户只能读自己数据
- **B.** 数据库不可停机
- **C.** 输入永远格式正确
- **D.** 值不改变预先定义的 SQL 结构

### 2. 报表需要选择排序列，最稳妥的做法是？

**题型**：选择题；**分值**：6 分。

- **A.** 把任意表名作为值参数
- **B.** 将选择映射到固定列名白名单，值另行绑定
- **C.** 仅删除空格
- **D.** 拼接前做 Base64 编码

### 3. 使用 ORM 后，仍重点审核哪处？

**题型**：选择题；**分值**：6 分。

- **A.** 原生查询与动态字符串接口
- **B.** 静态页面颜色
- **C.** 只看文件扩展名
- **D.** 不需要再审核

### 4. 存储过程内部拼接不可信文本，应如何判断？

**题型**：选择题；**分值**：6 分。

- **A.** 只要在数据库内就安全
- **B.** 只有 GET 才有风险
- **C.** 仍可能注入，需要绑定或有限结构映射
- **D.** 提高账号权限即可

### 5. 应用只需要读订单和更新状态，数据库账号应？

**题型**：选择题；**分值**：6 分。

- **A.** 拥有实例管理员权限
- **B.** 共享运维 root
- **C.** 能访问所有测试和生产库
- **D.** 仅获必要对象与操作权限，环境分离

### 6. 为何过滤引号与参数化不同？

**题型**：简答题；**分值**：15 分。

### 7. 查询已参数化，用户输入别人的订单 ID 后仍能读到订单。应修什么？

**题型**：简答题；**分值**：15 分。

### 8. 场景：动态报表允许选择列和日期，团队用字符串拼接，并以管理员账号查询。提出修复和验收。

**题型**：场景分析题；**分值**：40 分。
