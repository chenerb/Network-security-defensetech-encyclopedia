# XSS 与 CSRF · 节末小测（题目）

> **原创说明**：本卷为本项目原创练习，模拟课程考核与安全岗位追问，不声称改编自具体高校或公司的真实试题。仅用于教育学习和授权防御。

共 8 道主问题，满分 100 分。选择题为单选；简答和场景允许等价防御方案，但须说明边界、步骤与验证证据。

### 1. 同一段不可信文字要进入 HTML 正文和 JavaScript，上下文处理应？

**题型**：选择题；**分值**：6 分。

- **A.** 全部直接复用 HTML 编码
- **B.** 只删除一个标签
- **C.** 按各自上下文处理，尽量避免危险脚本插入
- **D.** 只启用 HTTPS

### 2. 允许用户提交有限富文本，主要防御是？

**题型**：选择题；**分值**：6 分。

- **A.** 维护中的 HTML 净化器并限制标签属性
- **B.** 相信编辑器界面
- **C.** 所有文字不检查直接渲染
- **D.** 只过滤关键词

### 3. HttpOnly Cookie 的准确作用是？

**题型**：选择题；**分值**：6 分。

- **A.** 阻止全部 XSS
- **B.** 限制脚本直接读取 Cookie，但不能阻止全部同源操作
- **C.** 取代所有 CSRF 令牌
- **D.** 证明用户意图

### 4. CSP 应如何定位？

**题型**：选择题；**分值**：6 分。

- **A.** 唯一 XSS 主防线
- **B.** 无需维护的安全保证
- **C.** 解决 SQL 注入
- **D.** 限制内容执行的纵深防御，不能替代输出处理

### 5. 页面已有同源 XSS，CSRF 令牌能否完整保护所有操作？

**题型**：选择题；**分值**：6 分。

- **A.** 一定能
- **B.** 令牌够长就能
- **C.** 不能；脚本可能读取令牌或调用同源接口
- **D.** 关闭日志就能

### 6. 解释 SameSite 与 CORS 为什么不能简单互换。

**题型**：简答题；**分值**：15 分。

### 7. 哪些请求需要 CSRF 防御，如何验收令牌？

**题型**：简答题；**分值**：15 分。

### 8. 场景：客服工单渲染留言，管理员以 Cookie 登录，关闭按钮触发状态变更 GET。设计整改与验证。

**题型**：场景分析题；**分值**：40 分。
