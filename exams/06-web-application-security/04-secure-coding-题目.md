# 安全编码与安全开发生命周期 · 节末小测（题目）

> **原创说明**：本卷为本项目原创练习，模拟课程考核与安全岗位追问，不声称改编自具体高校或公司的真实试题。仅用于教育学习和授权防御。

共 8 道主问题，满分 100 分。选择题为单选；简答和场景允许等价防御方案，但须说明边界、步骤与验证证据。

### 1. 哪条需求最容易安全验收？

**题型**：选择题；**分值**：6 分。

- **A.** 系统必须绝对安全
- **B.** 禁止任何错误
- **C.** 每次退款都由服务端验证订单归属，重试不重复退款
- **D.** 扫描器不要显示红色

### 2. SCA 主要帮助识别什么？

**题型**：选择题；**分值**：6 分。

- **A.** 依赖组件和已知风险
- **B.** 全部业务授权漏洞
- **C.** 网络容量保证
- **D.** 所有社会工程风险

### 3. SBOM 的合理结论是？

**题型**：选择题；**分值**：6 分。

- **A.** 列出组件就证明安全
- **B.** 提供组件清单，仍需来源、更新和风险治理
- **C.** 自动撤销泄漏凭据
- **D.** 替代所有审计

### 4. 授权依赖服务超时，应用应优先？

**题型**：选择题；**分值**：6 分。

- **A.** 默认允许以提高体验
- **B.** 关闭告警
- **C.** 返回数据库细节
- **D.** 按设计安全失败，避免未经确认的授权并维护一致性

### 5. CI 出现大量告警，最可持续的处理是？

**题型**：选择题；**分值**：6 分。

- **A.** 全部忽略
- **B.** 永久关闭安全扫描
- **C.** 按风险分级、验证误报、设有期限的例外与负责人
- **D.** 复制一份报告即可

### 6. 设计阶段如何通过威胁建模发现扫描器难以识别的问题？

**题型**：简答题；**分值**：15 分。

### 7. 为什么产物签名仍需配合构建身份与漏洞响应？

**题型**：简答题；**分值**：15 分。

### 8. 场景：支付团队在上线当天运行扫描，退款重复请求造成双重支出。设计持续改进。

**题型**：场景分析题；**分值**：40 分。
