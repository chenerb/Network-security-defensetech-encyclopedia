# 第六章 · 原创应用安全岗压力面（题目）

> **原创说明**：本卷为本项目原创练习，模拟课程考核与安全岗位追问，不声称改编自具体高校或公司的真实试题。仅用于教育学习和授权防御。

共 10 道主问题，满分 100 分。选择题为单选；简答和场景允许等价防御方案，但须说明边界、步骤与验证证据。

### 1. 面试官：用户已经登录，你为什么还要在每个对象上授权？

**题型**：压力面试题；**分值**：10 分。

**继续追问**：数据库用了行级策略，还要应用检查吗？

### 2. 面试官：ORM 全部用了，你还查 SQL 注入是不是重复劳动？

**题型**：压力面试题；**分值**：10 分。

**继续追问**：排序列为什么不直接放占位符？

### 3. 面试官：输入校验很严格，为什么还要输出编码？

**题型**：压力面试题；**分值**：10 分。

**继续追问**：数据库里已编码的内容能否直接输出？

### 4. 面试官：CSP 很严格，XSS 漏洞可以不修吗？

**题型**：压力面试题；**分值**：10 分。

**继续追问**：HttpOnly 能补上吗？

### 5. 面试官：接口是 JSON 和 POST，CSRF 令牌一定多余吧？

**题型**：压力面试题；**分值**：10 分。

**继续追问**：CORS 没有允许外站，不就安全了吗？

### 6. 面试官：权限服务超时默认允许，能保住可用性，你为何反对？

**题型**：压力面试题；**分值**：10 分。

**继续追问**：只读接口也要拒绝吗？

### 7. 面试官：扫描结果全绿，你准备签字保证安全吗？

**题型**：压力面试题；**分值**：10 分。

**继续追问**：如何让报告更有价值？

### 8. 面试官：有 SBOM 和产物签名，供应链风险还剩什么？

**题型**：压力面试题；**分值**：10 分。

**继续追问**：紧急依赖升级来不及完整测试？

### 9. 面试官：安全检查拖慢发布，你怎么避免团队绕过？

**题型**：压力面试题；**分值**：10 分。

**继续追问**：误报怎样关闭？

### 10. 面试官：退款接口返回错误，用户资金一定没变化吧？

**题型**：压力面试题；**分值**：10 分。

**继续追问**：只能做到最终一致怎么办？
