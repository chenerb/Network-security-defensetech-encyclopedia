## 答案与解析

### 1. 未知结果上下界（选择题，10 分）

**正确答案：B。**

**逐项解析：**

- **A（错误）**：分母为200，不能按100随意换算。
- **B（正确）**：下界9/200=4.5%，上界(9+10)/200=9.5%；未知不能事后全删。
- **C（错误）**：已有9次确认成功，零与证据矛盾。
- **D（错误）**：9/190是已知运行条件下比例，不能声称代表全部200次精确值。

**易错点：**忽略未知结果引入选择偏差。

**评分：**选对得 10 分，错选或不选得 0 分。

### 2. 混淆代理与最小权限（选择题，10 分）

**正确答案：D。**

**逐项解析：**

- **A（错误）**：越权读取已经发生，日志或后续轮次仍可能暴露。
- **B（错误）**：提醒不能减少服务账号能力。
- **C（错误）**：服务执行者需受用户委托边界限制，否则形成混淆代理。
- **D（正确）**：身份与对象控制在模型之外，最小化输入也减轻泄露后果。

**易错点：**把输出不说等同访问合法。

**评分：**选对得 10 分，错选或不选得 0 分。

### 3. 相关重复与场景覆盖（简答题，10 分）

**正确答案 / 参考要点：**

这些样本高度相关，主要检查近似输入下的随机行为，未覆盖不同来源、权限、工具、状态和业务后果。应定义场景矩阵与攻击者预算，用重复测量稳定性，同时按场景记录覆盖，加入独立保留集和正常任务。

**解析：**尝试数提高不代表覆盖范围同比增长，统计与语义独立性需要单独说明。

**易错点 / 踩坑点：**将重复输入数包装成威胁覆盖数。

**评分依据（10 分）：**相关性及单位 3 分；场景维度 3 分；重复用途 2 分；独立及正常集 2 分。 等价且符合情境的防御方案可得分；仅罗列产品、没有解释作用位置不计对应分。

### 4. 检索污染与训练泄漏归因（简答题，10 分）

**正确答案 / 参考要点：**

优先查用户/租户身份、文档权限元数据、向量检索过滤、缓存键与摘要复用边界，追踪秘密进入上下文的血缘。不能据此断言训练记忆泄露；需确认是否曾进入训练，并通过受控不检索对比等证据区分。

**解析：**当前证据指向检索和多租户边界，参数未变不能完全替代来源调查，但不支持直接归因训练。

**易错点 / 踩坑点：**看到秘密就归因模型参数，忽略跨租户缓存。

**评分依据（10 分）：**检索身份权限 3 分；索引缓存血缘 3 分；不直接归因 2 分；受控证据 2 分。 等价且符合情境的防御方案可得分；仅罗列产品、没有解释作用位置不计对应分。

### 5. 审批与并发状态竞态（场景题，15 分）

**正确答案 / 参考要点：**

1. 批准记录绑定真实用户、工具动作、订单、金额币种、收款目标、版本7、期限和唯一请求，保存不可变摘要。
2. 执行器重新读取当前身份权限及订单前提，发现版本不匹配先拒绝旧动作，不让模型自行认定“金额相同所以没关系”。
3. 如业务允许，重新计算动作并展示版本8及变化，取得新批准；通过条件更新或事务保证检查与提交的一致性。
4. 用幂等键、持久结果和状态机处理重试，区分未知提交、失败与完成，不能简单再退款一次。
5. 记录审批、版本比较、策略判断和账务结果，用并发变更、撤权、过期与重复的合成测试验证边界。

**解析：**金额相同不意味着资源状态与权利未变；幂等处理重复，条件更新处理状态竞态，两者互补。

**易错点 / 踩坑点：**只加确认弹窗没有参数绑定；把幂等键当授权；读完状态后非原子提交。

**评分依据（15 分）：**绑定字段 3 分；最新权限状态拒绝 3 分；重新批准及原子条件 3 分；幂等状态 3 分；审计和验证 3 分。 等价且符合情境的防御方案可得分；仅罗列产品、没有解释作用位置不计对应分。

### 6. 多代理工具输出洗白（场景题，15 分）

**正确答案 / 参考要点：**

1. 保留外部报告、检索片段、计划版本和委托身份，给内容跨代理传递来源与污点，计划不因重写成为授权。
2. 检索层按真实用户与租户过滤资料，阻止越权秘密进入上下文；检查已有上下文与缓存是否泄露。
3. 执行器独立检查导出对象、目的地、用途、额度与真实批准，对低信任权限声称拒绝，必要审批绑定具体动作。
4. 分别标记报告诱导、规划偏离、工具请求与实际导出，结合策略拒绝和业务记录确定影响，不用一次总标签。
5. 在授权隔离环境使用合成返回与模拟目的地回归，检验多轮转述、参数变化和正常任务，按风险恢复。

**解析：**信任属性应穿过多代理边界，执行权限不得由同伴文本自升。数据与行动边界均要检查。

**易错点 / 踩坑点：**把规划模型当权威授权者；只防最后一步而任意读取所有资料。

**评分依据（15 分）：**来源污点 3 分；数据权限 3 分；确定性执行和绑定 3 分；分层证据 3 分；隔离回归 3 分。 等价且符合情境的防御方案可得分；仅罗列产品、没有解释作用位置不计对应分。

### 7. 平均高分掩盖条件失败（场景题，15 分）

**正确答案 / 参考要点：**

1. 保存模型制品版本、签名来源、输入与来源标签，不将签名有效等同内容良性，也不立即断言恶意后门。
2. 定义可重复的来源和条件分组，查数据血缘、训练或检索阶段变更，核对新来源真实性与权限。
3. 用独立保留样例和受控模型/库组合对比，报告分组分母、错误类别及随机波动范围，检查其他来源。
4. 在不明确时限制高后果动作，冻结或隔离受影响来源或版本，沿索引、缓存及输出传播链修复，必要时恢复可信模型。
5. 在正常和风险场景复测后再逐步恢复，报告证据支持的结论与未知，要求供应商改进来源和发布验证。

**解析：**总体99%可掩盖稀有高影响异常，来源分群与独立对照帮助区分漂移、污染和配置问题。

**易错点 / 踩坑点：**高平均分排除所有风险；条件失败直接当确定后门；没防副作用。

**评分依据（15 分）：**留证及签名局限 3 分；阶段与来源 3 分；分组独立对照 3 分；限制及血缘修复 3 分；复测报告 3 分。 等价且符合情境的防御方案可得分；仅罗列产品、没有解释作用位置不计对应分。

### 8. 公平比较不同预算（场景题，15 分）

**正确答案 / 参考要点：**

1. 核对两个版本的模型、提示、检索、策略、工具与成功标准，说明不同尝试预算会改变至少一次成功机会。
2. 固定同一场景集和相同预算重新测试，记录采样设置与每次结果；另行报告不同预算下的风险曲线而不混成一个分数。
3. 分别计算场景成功率与单次尝试率，披露有效、失败、超时和未知的分类规则，不把相关重复当独立场景。
4. 用正常任务集评价误拒绝与完成率，重要结果人工复核实际工具执行和敏感泄露证据。
5. 保留独立评估集，按业务严重度解释差异和不确定性，只有匹配前提后才能支持版本优劣决策。

**解析：**预算是威胁模型的一部分，十次机会与一次机会不能直接作无条件比较。

**易错点 / 踩坑点：**只用最优指标；为了公平删除所有难场景；把发现数量当概率。

**评分依据（15 分）：**配置与预算混淆 3 分；匹配重测 3 分；分母和异常 3 分；正常集执行证据 3 分；独立与有限结论 3 分。 等价且符合情境的防御方案可得分；仅罗列产品、没有解释作用位置不计对应分。
