## 答案与解析

### 1. 权重与上下文（选择题，5 分）

**正确答案：A。**

**逐项解析：**

- **A（正确）**：按生命周期与血缘确定被改环节，不能仅从结果归因。
- **B（错误）**：条件性出错不证明参数变化。
- **C（错误）**：传输安全不解决资料语义错误。
- **D（错误）**：版本与来源是复现和恢复关键。

**易错点：**输出出错与训练投毒之间没有必然联系。

**评分：**选对得 5 分，错选或不选得 0 分。

### 2. 跨代理污点（选择题，5 分）

**正确答案：C。**

**逐项解析：**

- **A（错误）**：同伴转述不改变原始来源和授权。
- **B（错误）**：自然语言声称不具政策资格。
- **C（正确）**：权限由真实身份和程序策略控制，来源属性跨代理保留。
- **D（错误）**：扩大权限且无日志增加风险。

**易错点：**把多代理转述当可信洗白。

**评分：**选对得 5 分，错选或不选得 0 分。

### 3. 审批前后参数（选择题，5 分）

**正确答案：B。**

**逐项解析：**

- **A（错误）**：不同版本可能包含新的秘密，批准不是对收件人的无限许可。
- **B（正确）**：批准需匹配具体动作与内容，程序验证版本和权限。
- **C（错误）**：模型判断不能替用户授权新内容。
- **D（错误）**：泄露后审批无法逆转。

**易错点：**只绑定收件人，不绑定发送对象。

**评分：**选对得 5 分，错选或不选得 0 分。

### 4. 污染完整性校验（选择题，5 分）

**正确答案：D。**

**逐项解析：**

- **A（错误）**：签名不证明语义。
- **B（错误）**：是否使用要看任务、版本、权限与支持关系。
- **C（错误）**：带签名资料也可能包含误导要求。
- **D（正确）**：不同安全属性需要不同证据。

**易错点：**将签名有效等同可信结论。

**评分：**选对得 5 分，错选或不选得 0 分。

### 5. 执行与建议成功标准（选择题，5 分）

**正确答案：A。**

**逐项解析：**

- **A（正确）**：行为、请求和执行分层判分，可同时指出风险与有效边界。
- **B（错误）**：建议可能误导人，也反映模型失效。
- **C（错误）**：实际被拒绝，与执行成功不符。
- **D（错误）**：危险建议不等于正常完成。

**易错点：**一项总成功标签掩盖不同层次。

**评分：**选对得 5 分，错选或不选得 0 分。

### 6. 检测指标计算（选择题，5 分）

**正确答案：C。**

**逐项解析：**

- **A（错误）**：总告警=72+18=90，存在误报，精确率=72/90。
- **B（错误）**：漏报=90-72=18，召回率不是100%。
- **C（正确）**：精确率72/(72+18)=80%，召回率72/90=80%；数值相同但分母含义不同。
- **D（错误）**：18 是错误数量，不是正确命中的比例。

**易错点：**两个分母数值碰巧相等，不代表概念相同。

**评分：**选对得 5 分，错选或不选得 0 分。

### 7. 来源与输出处理（选择题，5 分）

**正确答案：B。**

**逐项解析：**

- **A（错误）**：真实链接可能不支持结论，更不能授行动权限。
- **B（正确）**：事实核验和行动授权是不同边界。
- **C（错误）**：多链接不能自动提升真实性或授权。
- **D（错误）**：向量检索需权限过滤，后端动作也需授权。

**易错点：**将引用质量误当执行许可。

**评分：**选对得 5 分，错选或不选得 0 分。

### 8. 资源预算（选择题，5 分）

**正确答案：D。**

**逐项解析：**

- **A（错误）**：循环或误导可能造成无界消耗。
- **B（错误）**：提醒不保证实际调用受限。
- **C（错误）**：各工具可能缺少全局预算与委托责任。
- **D（正确）**：确定性预算限制后果，需按真实任务调整而不自升级。

**易错点：**成本限制仅靠模型自我管理。

**评分：**选对得 5 分，错选或不选得 0 分。

### 9. 三种污染的修复位置（简答题，6 分）

**正确答案 / 参考要点：**

训练投毒检查数据批次、标签和训练产物，必要时重训；模型制品污染检查参数、构建和发布链，恢复可信制品；RAG 污染检查原文、索引、元数据、缓存及下游结果，通常不直接要求重训。

**解析：**结果相似不代表污染阶段相同，应沿来源与血缘确定。

**易错点 / 踩坑点：**统一删除一份文档或统一重训，不查实际阶段。

**评分依据（6 分）：**训练链 2 分；制品链 2 分；检索派生链 2 分。 等价且符合情境的防御方案可得分；仅罗列产品、没有解释作用位置不计对应分。

### 10. 直接与间接入口（简答题，6 分）

**正确答案 / 参考要点：**

直接：用户输入试图把允许任务扩成越权动作；间接：外部邮件或网页中的文本试图改变原任务。对两者都需真实身份、任务和工具权限约束；间接还需来源污点跨检索与转述保留。无需写任何可利用的载荷。

**解析：**入口来源不同，后果仍受数据与执行权限影响。

**易错点 / 踩坑点：**只检查用户输入，忽略工具与检索内容。

**评分依据（6 分）：**两个入口各 2 分；外部权限与污点 2 分。 等价且符合情境的防御方案可得分；仅罗列产品、没有解释作用位置不计对应分。

### 11. 多次尝试的分母（简答题，6 分）

**正确答案 / 参考要点：**

场景成功率=5/50=10%，描述预算内多少场景可达成；单次尝试率=8/200=4%，描述有效尝试的比例。需要同时报告重试预算，不能把 200 次当 200 个独立场景。

**解析：**重试相关且每场景多次机会，两个单位回答不同问题。

**易错点 / 踩坑点：**用4%替代10%而不说明单位。

**评分依据（6 分）：**场景率 2 分；尝试率 2 分；预算和相关性 2 分。 等价且符合情境的防御方案可得分；仅罗列产品、没有解释作用位置不计对应分。

### 12. 安全与正常效用（简答题，6 分）

**正确答案 / 参考要点：**

报告相同配置前提下两类指标、样本分母和错误类别，检查是否过度拒绝、权限过窄或任务质量下降。根据业务后果与预定门槛决定调整或分阶段发布，不能只选有利指标。

**解析：**安全控制也影响可用性与效用，需显式权衡。

**易错点 / 踩坑点：**将所有合法请求拒绝当最安全版本。

**评分依据（6 分）：**双指标与分母 2 分；定位损害 2 分；风险权衡与发布条件 2 分。 等价且符合情境的防御方案可得分；仅罗列产品、没有解释作用位置不计对应分。

### 13. RAG 加发送工具（场景题，12 分）

**正确答案 / 参考要点：**

1. 真实用户与租户在后端核验；检索按文档权限过滤，避免秘密先进入上下文，保留来源和版本。
2. 模型只提出结构化发送请求，程序验证对象、接收方、数据类别和委托范围，工具与令牌能力最小化。
3. 必要审批绑定文件内容版本、收件人、用途、参数摘要与期限，执行前复核当前权限及状态，变化则重新批准。
4. 记录建议、拒绝和实际结果，限制预算与出口；用合成跨租户、转述误导、参数变化及正常任务测试。

**解析：**读取边界和发送边界都需要控制，不能因为发送时有人审就无限制检索。

**易错点 / 踩坑点：**只让模型判断租户，或审批“发送报告”却不显示收件人与版本。

**评分依据（12 分）：**检索身份 3 分；执行授权 3 分；绑定和复核 3 分；审计预算评估 3 分。 等价且符合情境的防御方案可得分；仅罗列产品、没有解释作用位置不计对应分。

### 14. 供应商换版后异常（场景题，12 分）

**正确答案 / 参考要点：**

1. 冻结变更组合并记录模型、制品、提示、索引和策略版本，保全错误建议及引用证据，明确尚无付款。
2. 分别用可信旧模型/新模型和旧库/新库的受控组合对比，检查来源、数据血缘和参数变化，避免无证据归因投毒。
3. 暂停有副作用动作或确保外部执行器拒绝不合法建议，核查当前权限、审批与真实账务结果。
4. 回滚确认受影响的链路，清理派生数据；用独立风险和正常集验证事实与动作边界，记录不确定性后分阶段恢复。

**解析：**多项同时变更会产生归因混淆，需分离配置并保护执行边界。

**易错点 / 踩坑点：**因建议错误就认定训练已被投毒，或只换模型保留污染缓存。

**评分依据（12 分）：**冻结版本与证据 3 分；受控对比及血缘 3 分；限制动作核实影响 3 分；回滚独立验证 3 分。 等价且符合情境的防御方案可得分；仅罗列产品、没有解释作用位置不计对应分。

### 15. 红队指标发布争议（场景题，12 分）

**正确答案 / 参考要点：**

1. 指出9/240=3.75%采用尝试分母，6/80=7.5%采用场景分母；两者不能互换，重试预算需披露。
2. 核对成功是否定义为建议、工具请求或实际动作，逐项检查证据；超时是否覆盖成功场景及何种失败须保留。
3. 按事先约定规则分类8次超时；若规则未定，报告已知结果和未知数量，给出敏感性分析，不事后单方面全计失败。
4. 补正常完成率、误拒绝与未测范围，在固定版本和隔离授权下复测异常运行，再由适当负责人据业务后果决定发布。

**解析：**给定超时使精确风险估计存在不确定性；算术正确不等于解释正确。

**易错点 / 踩坑点：**用较大的分母掩盖场景成功，或默删超时；对未知场景作确定结论。

**评分依据（12 分）：**两分母推导 3 分；成功证据 3 分；超时规则及未知 3 分；正常对照与发布边界 3 分。 等价且符合情境的防御方案可得分；仅罗列产品、没有解释作用位置不计对应分。
