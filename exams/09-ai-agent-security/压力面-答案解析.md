## 答案与解析

### 1. 系统提示与授权（面试题，10 分）

**正确答案 / 参考要点：**

1. 说明模型与审查模型都处理不可信内容，输出是建议，不能证明真实身份和权限。
2. 执行器在模型之外核验用户、租户、对象、动作与参数，使用范围令牌，拒绝不符合策略的动作。
3. 高影响审批绑定具体内容与状态，执行前复核最新条件，记录真实操作和拒绝。
4. 用越权、工具返回误导、过期与状态变更样例证明边界，与模型行为评估分开。

**解析：**概率性内容防护有帮助，但不能承担最终确定性授权。

**可能追问与应答：**权限服务也可能有漏洞，怎么办？ 权限服务也需最小接口、代码评审和有针对性的授权测试，后端拒绝记录与业务结果可验证边界；存在漏洞可能性不构成取消边界的理由。

**易错点 / 踩坑点：**把第二个模型称为绝对可靠裁判。

**评分依据（10 分）：**控制位置3分；权限范围3分；绑定复核2分；验证分层2分。 等价且符合情境的防御方案可得分；仅罗列产品、没有解释作用位置不计对应分。

### 2. 间接注入与资料价值（面试题，10 分）

**正确答案 / 参考要点：**

1. 不可信是权限与来源属性，不代表资料一律无价值；任务仍可读取获授权的数据。
2. 按用户权限检索，保留来源、版本与污点，将内容当资料分析而非自带命令。
3. 验证引用支持度与敏感输出，工具动作通过外部身份和参数授权，必要人审。
4. 用正常资料与风险来源评估，检查多轮转述及误拒绝，按用途调整而不是全部拒绝。

**解析：**资料可以提供事实，但不能自授能力；多层边界允许保留效用。

**可能追问与应答：**工具返回来自自己的服务器，是否就可信？ 自有通道不代表内容由有权主体创建，数据库可能包含用户上传和第三方资料；根据内容来源标记，不能按服务器归属一刀切。

**易错点 / 踩坑点：**完全拒绝外部资料，或只加关键词过滤。

**评分依据（10 分）：**用途区分3分；检索污点3分；输出执行2分；效用评估2分。 等价且符合情境的防御方案可得分；仅罗列产品、没有解释作用位置不计对应分。

### 3. 一次同意的范围（面试题，10 分）

**正确答案 / 参考要点：**

1. 将任务授权具体化为对象、动作、目的地、额度、时限和允许自主程度，不能当无限权限。
2. 低影响且在明确范围内的动作可预授权，高影响或变化动作展示差异并审批。
3. 批准绑定不可变参数与状态版本，执行前复核当前权限，使用条件提交和幂等。
4. 记录实际动作和预算，设置停止开关，评估正常完成与误拒绝以优化流程。

**解析：**减少重复提示应通过明确有限委托，而非取消权限与状态边界。

**可能追问与应答：**收件人没变，但附件内容变了还需审批吗？ 需要核对批准绑定的内容与版本；若变化超出先前明确授权，展示新内容与后果重新审批，执行前再次验证。

**易错点 / 踩坑点：**把口头全权变成长期管理员许可，或每一步盲目弹窗。

**评分依据（10 分）：**授权具体化3分；风险分层3分；绑定复核2分；审计效用2分。 等价且符合情境的防御方案可得分；仅罗列产品、没有解释作用位置不计对应分。

### 4. 投毒调查的归因（面试题，10 分）

**正确答案 / 参考要点：**

1. 保全模型、提示、知识库、索引和策略版本及错误样例，确认训练是否实际发生。
2. 区分训练数据、模型制品、RAG污染、推理条件与普通漂移，检查来源和血缘。
3. 用受控组合与独立样例定位受影响阶段，同时限制高后果动作。
4. 回滚或修复实际链路并清理派生对象，必要时重训，正常和风险双集复测。

**解析：**重训成本高且可能不触及错误检索库，修复需先有阶段证据。

**可能追问与应答：**签名和校验全正常，还要查吗？ 需要。签名证明对应制品来源和完整性，不证明数据语义良性；仍核查任务条件、检索内容和行为。

**易错点 / 踩坑点：**无证据归因投毒；只重训却保留污染缓存。

**评分依据（10 分）：**留证版本3分；阶段血缘3分；对比控风险2分；针对修复复测2分。 等价且符合情境的防御方案可得分；仅罗列产品、没有解释作用位置不计对应分。

### 5. 拒绝率与发布（面试题，10 分）

**正确答案 / 参考要点：**

1. 先核对危险与正常集分母、成功标准和有效运行，拒绝率不是执行安全的完整证明。
2. 指出正常完成率40%意味着本正常集60%未完成，但未完成不一定全为误拒绝，要分错误类别。
3. 检查过度拒绝、任务质量、检索与工具权限，评估未被拒绝样本的后果及实际执行边界。
4. 按预定业务门槛调整控制并复测，报告风险与效用权衡，在关键任务未达到验收时不作无条件发布承诺。

**解析：**数字应解释为对应样本结果，既不夸大安全，也不把所有失败都叫误拒绝。

**可能追问与应答：**60%未完成能否都算安全防护成功？ 不能。正常任务未完成可能是误拒绝、错误答案、工具故障或超时，必须分类，合法任务失败也不是防护成功。

**易错点 / 踩坑点：**把99%当安全认证；把60%全部算误拒绝。

**评分依据（10 分）：**定义分母3分；40%正确解释3分；定位及后果2分；发布门槛2分。 等价且符合情境的防御方案可得分；仅罗列产品、没有解释作用位置不计对应分。

### 6. 场景分母压力（面试题，10 分）

**正确答案 / 参考要点：**

1. 明确10/500=2%是尝试单位，5/20=25%是场景至少一次成功单位。
2. 记录每场景预算与重复分布，不能用500次假称500种独立覆盖。
3. 分别报告成功类型、严重度与工具执行证据，按预定义规则处理超时和未知。
4. 解释两指标回答的问题，保留完整结果与正常任务，按业务风险优先修复可成功场景。

**解析：**隐藏场景成功率会掩盖攻击者在多次机会下可达到的结果，真实分母必须透明。

**可能追问与应答：**如果五个场景都用了最多重试怎么办？ 披露预算分布，并可按同一预算重新比较或报告预算曲线；不等次数需在结论中说明，不宜将所有场景当等机会。

**易错点 / 踩坑点：**被压力要求改分母，或把相关重试当独立样本。

**评分依据（10 分）：**两个计算3分；预算相关性3分；证据异常2分；诚实风险报告2分。 等价且符合情境的防御方案可得分；仅罗列产品、没有解释作用位置不计对应分。

### 7. 供应商秘密留存（面试题，10 分）

**正确答案 / 参考要点：**

1. 不用于训练只描述一种用途，不说明留存、日志、地域、访问、子处理者或全部合同条件。
2. 按数据分类、业务用途和真实授权确定可上传范围，核对供应商现行政策及适用要求。
3. 最小化或脱敏输入，必要时选择符合约束的部署，限制供应商和本方日志访问。
4. 记录配置、负责人、数据处理和删除机制，评估敏感回显与异常访问，持续复查政策变化。

**解析：**训练用途与完整数据处理边界不同，不能用一句承诺代替风险评估。

**可能追问与应答：**把资料转换成向量就可随意上传吗？ 不能。向量可能泄露来源信息，不是加密；同样需要数据授权、供应商政策和用途范围控制。

**易错点 / 踩坑点：**“不训练”等同不保存；向量等同加密。

**评分依据（10 分）：**用途区别3分；分类政策3分；最小化边界2分；记录复查2分。 等价且符合情境的防御方案可得分；仅罗列产品、没有解释作用位置不计对应分。

### 8. 多代理可靠性（面试题，10 分）

**正确答案 / 参考要点：**

1. 投票可能共享同一不可信来源与错误前提，数量不等于独立授权证据。
2. 保留原始来源、污点和委托链，核对真实用户、租户及允许任务。
3. 执行器独立验证导出对象、目的地、参数、限额和当前批准，代理文本不扩大权限。
4. 评估建议、请求、实际动作的不同结果，加入共享来源误导与正常协作回归。

**解析：**内容共识无法创造权限，相关模型也未必提供独立置信度。

**可能追问与应答：**如果三个代理模型来自不同厂商呢？ 仍不能创建授权，且共有数据与任务前提会造成相关错误；不同厂商有助多样性但不代替真实权限系统。

**易错点 / 踩坑点：**把投票当授权，或忽略共同输入相关性。

**评分依据（10 分）：**共因判断3分；来源委托3分；外部执行2分；回归分层2分。 等价且符合情境的防御方案可得分；仅罗列产品、没有解释作用位置不计对应分。

### 9. 实际工具结果证明（面试题，10 分）

**正确答案 / 参考要点：**

1. 模型总结可能不准确，工具成功可能只表示接收或排队，需理解接口语义。
2. 核对真实交易标识、账务状态、对象与金额，区分待处理、失败、完成和未知。
3. 发生超时或未知时按幂等和状态查询处理，不能盲目重复有副作用请求。
4. 保留批准、请求、执行与最终业务记录，配置条件提交和异常人工处理。

**解析：**调用完成、消息接受和账务生效是不同层，审计要能证明真实副作用。

**可能追问与应答：**查不到结果时是否再发一次？ 先用唯一请求标识查询持久状态或人工确认，依据接口幂等语义恢复；未知不等于失败，避免再次产生副作用。

**易错点 / 踩坑点：**对话宣称完成等同业务完成；超时直接重试导致重复支付。

**评分依据（10 分）：**语义区别3分；业务证据3分；幂等未知2分；审计异常2分。 等价且符合情境的防御方案可得分；仅罗列产品、没有解释作用位置不计对应分。

### 10. AI 红队授权范围（面试题，10 分）

**正确答案 / 参考要点：**

1. 明确红队授权覆盖系统、数据、工具和第三方范围，公共可访问不等于获准测试或联系客户。
2. 使用合成资料、模拟外部返回和隔离收件人验证企业侧边界，规定预算与停止条件。
3. 固定版本、成功标准与分母，检查模型行为与受控执行；不把模拟结果夸称外部网站安全。
4. 必要的真实外部验证另获明确许可、最小化影响，结束后撤权、处理日志并安排回归。

**解析：**红队价值来自可解释证据，未授权外部副作用会制造新的风险。

**可能追问与应答：**老板同意测试，是否覆盖客户和网站？ 老板只可授权其有权管辖的资产与数据，第三方和客户副作用需相应许可或已有明确委托；优先使用隔离模拟。

**易错点 / 踩坑点：**公开网站就是授权；测试邮件无需收件方和数据范围确认。

**评分依据（10 分）：**授权边界3分；隔离低影响3分；版本证据2分；外部许可清理2分。 等价且符合情境的防御方案可得分；仅罗列产品、没有解释作用位置不计对应分。

## 自测建议

优先回看错题对应正文，尝试解释错误选项为何不成立。场景和面试题按证据、权限、处置顺序与验收效果评分；如果方案会直接导致越权、破坏证据或未授权测试，相关控制项不得分。
