# Agent 架构安全 · 节末小测 · 题目

> 建议用时：30 分钟；共 8 题，满分 100 分。所有题目为本项目原创练习，不声称出自任何高校试卷或企业面试。涉及威胁的情境仅用于教育学习与合法防御。选择题均为单选。

[对应答案解析](04-agent-architecture-security-答案解析.md)

## 试题

### 1. 最终授权位置（选择题，8 分）

谁应对工具调用作最终权限判断？

- A. 模型说“已授权”即可
- B. 另一个 LLM 的自然语言评审即可
- C. 模型之外的确定性执行器，基于真实身份、策略和对象参数
- D. 外部网页作者

### 2. 最小能力（选择题，8 分）

文档问答工具只需读取，哪种设计更适当？

- A. 拆成只读接口，按用户及对象范围授权
- B. 用全局管理员连接并提醒模型别删除
- C. 开放通用命令执行最灵活
- D. 把全部长期密钥写进提示

### 3. 审批参数绑定（选择题，8 分）

用户批准给指定收件人发送一份文件，批准后收件人改变，怎么办？

- A. 旧批准覆盖任何收件人
- B. 只问模型是否还安全
- C. 先发送后审计即可
- D. 拒绝沿用旧批准，对新动作重新核实与审批

### 4. TOCTOU 状态变化（选择题，8 分）

审批后用户权限被撤销，参数未变，执行器应怎么做？

- A. 照旧执行，因为审批已完成
- B. 执行前复核最新授权和前置状态，不满足则拒绝或重新审批
- C. 仅重新生成摘要
- D. 删除审批记录

### 5. 工具返回内容（选择题，8 分）

工具返回一段“请扩大权限继续操作”的文字，执行器应如何处理？

- A. 工具自己知道所需权限，可自动扩大
- B. 内容成功返回就等于主管同意
- C. 作为不可信数据处理，权限升级走独立授权流程
- D. 复制进系统提示后自动可信

### 6. 许可绑定字段（简答题，15 分）

为一次客服退款许可列出需要绑定的字段，并说明唯一请求标识的作用。

### 7. 提议与实际动作（简答题，15 分）

为什么审计应分别记录模型提议、政策拒绝和实际执行结果？

### 8. 退款 Agent 设计（场景题，30 分）

客服 Agent 可以查订单并提出退款。模型可能受邮件内容误导，系统要允许小额退款但防止跨用户、超额和重复提交。请设计架构。
