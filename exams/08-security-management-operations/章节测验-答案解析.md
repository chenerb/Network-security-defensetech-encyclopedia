## 答案与解析

### 1. 风险与检测优先级（选择题，5 分）

**正确答案：B。**

**逐项解析：**

- **A（错误）**：量大不代表最有业务价值，也可能成本高但难用于检测。
- **B（正确）**：风险排序决定需要回答的问题，再确认数据能支持检测。
- **C（错误）**：合规要求要满足，但不应忽略关键业务威胁。
- **D（错误）**：缺失、延迟和字段错误会让规则失效。

**易错点：**将数据规模和风险收益混为一谈。

**评分：**选对得 5 分，错选或不选得 0 分。

### 2. 合规证据与演练证据（选择题，5 分）

**正确答案：C。**

**逐项解析：**

- **A（错误）**：有限证据不保证所有情况。
- **B（错误）**：纸面制度不能代替实际执行。
- **C（正确）**：设计存在和运行有效是两个不同证据层，需结合看。
- **D（错误）**：演练记录能支持控制效果与改进。

**易错点：**把写出流程等同流程已经可用。

**评分：**选对得 5 分，错选或不选得 0 分。

### 3. 检测数值推导（选择题，5 分）

**正确答案：A。**

**逐项解析：**

- **A（正确）**：精确率=36/120=30%；召回率=36/60=60%，其余 84 个告警为误报、24 个异常为漏报。
- **B（错误）**：调换分母后概念错误。
- **C（错误）**：20% 未对应正确分母。
- **D（错误）**：存在 84 个误报，精确率不可能为 100%。

**易错点：**忽略未告警异常，或把总告警当总异常。

**评分：**选对得 5 分，错选或不选得 0 分。

### 4. 原始时间与采集时间（选择题，5 分）

**正确答案：B。**

**逐项解析：**

- **A（错误）**：积压会打乱接收顺序，且不同源到达速度不同。
- **B（正确）**：两种时间都保留有助判断因果和数据质量，需核对时钟偏差。
- **C（错误）**：迟到记录可能是重要证据。
- **D（错误）**：人为统一时间会毁坏线索。

**易错点：**用平台收到日志的时间代替事件发生时间。

**评分：**选对得 5 分，错选或不选得 0 分。

### 5. 响应优先级（选择题，5 分）

**正确答案：D。**

**逐项解析：**

- **A（错误）**：等待可能扩大外泄。
- **B（错误）**：业务可用不代表机密性没有受损。
- **C（错误）**：清盘可丢失线索，不能自动处理入口与外泄令牌。
- **D（正确）**：安全和证据可并行安排；必须记录动作影响与未知。

**易错点：**用单一固定动作解决所有事故。

**评分：**选对得 5 分，错选或不选得 0 分。

### 6. 外包责任（选择题，5 分）

**正确答案：C。**

**逐项解析：**

- **A（错误）**：服务不能消除业务所有者责任。
- **B（错误）**：谁能停用账号或隔离资产必须约定。
- **C（正确）**：分工、协议和证据是外包控制的一部分。
- **D（错误）**：第三方测试仍需独立授权。

**易错点：**把采购服务理解为转移全部风险。

**评分：**选对得 5 分，错选或不选得 0 分。

### 7. 红队停测与事故交接（选择题，5 分）

**正确答案：A。**

**逐项解析：**

- **A（正确）**：超出约定或危及真实数据需及时控制，并交接响应。
- **B（错误）**：继续扩大影响不符合低影响验证和边界。
- **C（错误）**：隐藏记录妨碍调查。
- **D（错误）**：授权不能由执行者或新发现自动扩大。

**易错点：**为了报告效果更显著而越界。

**评分：**选对得 5 分，错选或不选得 0 分。

### 8. 已验证覆盖（选择题，5 分）

**正确答案：D。**

**逐项解析：**

- **A（错误）**：标签无实际数据不证明检测。
- **B（错误）**：动作发生不代表监控看到。
- **C（错误）**：颜色不能解释链路。
- **D（正确）**：端到端记录支持该场景下能力，仍需报告前提与未测路径。

**易错点：**将动作、遥测、检测和响应当同一件事。

**评分：**选对得 5 分，错选或不选得 0 分。

### 9. 风险登记册最小闭环（简答题，6 分）

**正确答案 / 参考要点：**

描述资产、威胁、弱点与业务后果；确定风险所有者和控制负责人；选择处理及期限；验证控制与剩余风险，必要时有权接受；复测通过或系统退役后按证据关闭。

**解析：**风险关闭不是删除条目，应有验证依据与责任。

**易错点 / 踩坑点：**修复工单完成就自动关闭业务风险。

**评分依据（6 分）：**风险描述 2 分；责任措施期限 2 分；验证和关闭证据 2 分。 等价且符合情境的防御方案可得分；仅罗列产品、没有解释作用位置不计对应分。

### 10. 日志隐私与取证（简答题，6 分）

**正确答案 / 参考要点：**

按用途最小化与脱敏，限制日志访问和写入，约定留存期限；事故发生后按授权保全相关原始记录与受控副本，登记访问和交接，避免将全部敏感日志无限期复制给所有人员。

**解析：**隐私限制与证据保全均需有范围和责任，并不互相取消。

**易错点 / 踩坑点：**以取证为由永久保存所有人的数据。

**评分依据（6 分）：**最小化与访问控制 2 分；授权留证 2 分；留存交接 2 分。 等价且符合情境的防御方案可得分；仅罗列产品、没有解释作用位置不计对应分。

### 11. 哈希与来源（简答题，6 分）

**正确答案 / 参考要点：**

哈希帮助发现记录后的内容变化，不能证明采集前真实或来自哪台机器。还需设备或资源标识、采集时间与方法、人员、工具、影响和保管链，说明证据的取得与转交。

**解析：**完整性、来源和授权是不同证据层。

**易错点 / 踩坑点：**拿两个一致哈希直接断言真实身份。

**评分依据（6 分）：**校验能力 2 分；来源与方法 2 分；保管链及边界 2 分。 等价且符合情境的防御方案可得分；仅罗列产品、没有解释作用位置不计对应分。

### 12. 整改复测对照（简答题，6 分）

**正确答案 / 参考要点：**

异常场景检验原缺口是否被覆盖；正常对照检查规则是否大量误报或阻断合法业务。固定前提、版本和判分方法，保留实际遥测、告警、分诊及处置证据。

**解析：**把所有行为都标为异常可以提升检测数量，却损害有效性。

**易错点 / 踩坑点：**只追求告警响了，不检查正常业务。

**评分依据（6 分）：**异常目的 2 分；正常目的 2 分；版本和证据 2 分。 等价且符合情境的防御方案可得分；仅罗列产品、没有解释作用位置不计对应分。

### 13. 业务风险驱动运营（场景题，12 分）

**正确答案 / 参考要点：**

1. 将支付中断、配置篡改与证据缺失分别写成业务风险，列出资产依赖、已有控制和未知，合规材料作为部分证据。
2. 按可能影响优先安排恢复验证和云审计健康修复，指定业务、运维与SOC负责人、时间及临时补偿控制。
3. 执行隔离的恢复演练及正常/异常日志验证，检查业务功能、数据完整性、告警升级和恢复所用时间。
4. 重新评估剩余风险，由有权人员决定限期接受或继续整改；上线条件与复查触发点形成可核验记录。

**解析：**两项缺口分别影响恢复能力和可见性，不能用已通过审计替代验证。

**易错点 / 踩坑点：**只采购新产品，没恢复测试或数据健康验收。

**评分依据（12 分）：**业务风险 3 分；优先措施责任 3 分；实际验证 3 分；剩余风险及上线决策 3 分。 等价且符合情境的防御方案可得分；仅罗列产品、没有解释作用位置不计对应分。

### 14. 事故与服务商协作（场景题，12 分）

**正确答案 / 参考要点：**

1. 核验告警与读取证据，确定主体、租户、时间、范围和持续性，启动组织响应负责人而非让服务商自行越权。
2. 由已授权团队限制会话或数据访问，服务商并行保全自身原始告警和日志；记录时钟、动作与交接。
3. 结合云审计、身份与数据日志分析入口和影响，按需要轮换凭据，修复问题并从可信状态恢复。
4. 验证业务、监控与权限，评估报告责任并复盘升级延迟，将服务合同与预案补上明确授权和紧急联络。

**解析：**服务分工不意味着没人负责高影响动作，必须有明确升级链。

**易错点 / 踩坑点：**让模型或服务商临时决定组织权限；忽视凭据泄露后续。

**评分依据（12 分）：**核验分级 3 分；授权遏制和证据交接 3 分；根因与恢复 3 分；验收及改进 3 分。 等价且符合情境的防御方案可得分；仅罗列产品、没有解释作用位置不计对应分。

### 15. 演练发现转为风险处理（场景题，12 分）

**正确答案 / 参考要点：**

1. 报告明确约定资产、动作、合成资料及测试时窗，分别记录动作成功、遥测缺失和未产生真实外泄，避免夸大为全面失陷。
2. 将采集与检测盲区连接到相应业务风险，排查源心跳、字段、权限和链路，指定整改负责人与期限。
3. 恢复采集后用相同异常场景和正常对照，验证规则、分诊及授权响应，记录版本和实际结果。
4. 撤销演练权限并处理资料，更新当前画像和剩余风险；报告覆盖限制与未测条件，未通过则继续整改。

**解析：**不成功的检测也能形成清晰风险证据，关键是区分原因与影响。

**易错点 / 踩坑点：**因无真实外泄而忽略盲区，或因测试读取成功声称所有系统被攻破。

**评分依据（12 分）：**限定报告与证据 3 分；风险和责任 3 分；复测验证 3 分；清理更新与边界 3 分。 等价且符合情境的防御方案可得分；仅罗列产品、没有解释作用位置不计对应分。

## 自测建议
