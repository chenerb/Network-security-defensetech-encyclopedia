## 答案与解析

### 1. 低基率告警质量（选择题，10 分）

**正确答案：A。**

**逐项解析：**

- **A（正确）**：召回=18/20；精确率=18/118≈15.25%。低基率时较少的正常误报也可能占多数告警。
- **B（错误）**：调换分母，概念错误。
- **C（错误）**：假阳性率的分母是正常活动9980，而100/118是告警中的误报比例。
- **D（错误）**：只支持本集和本前提，不能外推全部威胁。

**易错点：**总体准确率或高召回率掩盖实际告警可信度。

**评分：**选对得 10 分，错选或不选得 0 分。

### 2. 时间不确定性与因果（选择题，10 分）

**正确答案：B。**

**逐项解析：**

- **A（错误）**：显示时间未反映误差，不能确定先后，更不能直接证明因果。
- **B（正确）**：A区间09:59:57–10:00:03，B区间09:59:58–10:00:06，有重叠。
- **C（错误）**：哈希保护记录内容，不校准时钟。
- **D（错误）**：仍可用会话、请求、对象状态和其他记录缩小不确定性。

**易错点：**精确显示的时间不等于精确发生时间。

**评分：**选对得 10 分，错选或不选得 0 分。

### 3. 风险分值与连锁依赖（简答题，10 分）

**正确答案 / 参考要点：**

同分只是排序编码，不能表示相同概率与损失。共用平台有相关故障和级联影响，需识别下游依赖、集中权限及恢复顺序，评估联合后果与不确定性，再安排控制。可优先验证隔离、冗余、凭据范围和分阶段恢复。

**解析：**风险矩阵可能把不同影响压成同一分值，业务依赖又破坏独立假设。

**易错点 / 踩坑点：**把同分当同风险，把各业务损失简单相加却不考虑共因。

**评分依据（10 分）：**序数局限 3 分；依赖与共因 3 分；联合影响和证据 2 分；控制及验证 2 分。 等价且符合情境的防御方案可得分；仅罗列产品、没有解释作用位置不计对应分。

### 4. 运营指标变化解释（简答题，10 分）

**正确答案 / 参考要点：**

明确响应起止点、未完成事件处理、严重度和样本范围，报告分层时间、长尾和未完成数量；检查是否通过早关闭、降低等级或只处理简单告警改善平均值。将控制有效性与业务结果加入复核。

**解析：**平均数不代表所有事件，也容易受样本构成与关闭规则影响。

**易错点 / 踩坑点：**仅公布一个下降百分比，排除所有仍打开的事故。

**评分依据（10 分）：**定义与未完成样本 3 分；分层长尾 3 分；操纵或构成解释 2 分；业务验证 2 分。 等价且符合情境的防御方案可得分；仅罗列产品、没有解释作用位置不计对应分。

### 5. 误报自动封禁风暴（场景题，15 分）

**正确答案 / 参考要点：**

1. 暂停高影响自动封禁或改为受控分诊，保全规则版本、告警、真实操作和业务中断记录，避免继续放大损害。
2. 建立可信正常与异常标注集，核验身份、时间、对象、缺失字段和关联窗口，计算精确率、召回率及实际误禁影响。
3. 按关键账号、业务时段和严重度设授权边界，采用可逆限制、例外与适当人审，明确紧急解禁责任。
4. 在隔离环境先验证异常能否检测与遏制、正常业务是否完成，再分阶段上线，监控数据健康与长尾响应。
5. 将误伤和漏检纳入风险登记与复盘，设置停止阈值和回滚，记录服务中断与安全收益的证据。

**解析：**高封禁数量可能只说明规则噪声和权限过大。需要把检测效果与处置副作用同时评价。

**易错点 / 踩坑点：**只提高阈值而不查字段错误；取消所有检测而无替代可见性。

**评分依据（15 分）：**停止放大并留证 3 分；标注和计算 3 分；授权可逆处置 3 分；双对照验证 3 分；风险与回滚 3 分。 等价且符合情境的防御方案可得分；仅罗列产品、没有解释作用位置不计对应分。

### 6. 云快照证据不足（场景题，15 分）

**正确答案 / 参考要点：**

1. 限定已知结论：快照及校验保护对应对象的记录完整性，不能覆盖控制面行为、历史权限或真实操作者。
2. 按授权联系云与身份管理方保全可用审计、会话、资源版本和访问记录，记录留存窗口、区域、时区及缺失范围。
3. 建立采集方法、工具、人员和交接记录，分析受控副本，交叉核对资源变更与数据访问。
4. 结合证据评估凭据泄露与持续影响，采取必要撤销、轮换和权限复核；恢复功能仍需验证入口与监控。
5. 报告事实、推断与无法排除的历史区间，完善平时控制面日志及响应预案，不以缺日志证明没事件。

**解析：**证据覆盖对象与声明范围必须匹配。恢复快照正常并不反证所有历史行为。

**易错点 / 踩坑点：**哈希一致就断言没被入侵；把数据面快照当完整云审计。

**评分依据（15 分）：**限定结论 3 分；授权补证与窗口 3 分；保管链核验 3 分；凭据及恢复 3 分；未知与改进 3 分。 等价且符合情境的防御方案可得分；仅罗列产品、没有解释作用位置不计对应分。

### 7. 第三方测试边界漂移（场景题，15 分）

**正确答案 / 参考要点：**

1. 核对当前RoE与资产归属，外部搜索不因系统依赖或蓝队要求自动纳入授权；暂停会影响第三方的动作。
2. 向有权负责人确认第三方许可、动作、时窗与停止条件，未经许可不能开展；保存发现但最小化外部信息。
3. 使用模拟搜索返回、合成资料和隔离执行器验证企业侧来源标记、输入处理、日志和响应，不冒充测试了第三方服务。
4. 把未测依赖及相应业务风险写入报告，明确哪些企业侧控制已验证、哪些外部条件未知，并指定后续负责人。
5. 清理临时权限和资料，获新授权后按新前提单独测试、比较证据并复盘边界确认流程。

**解析：**合法授权与证据覆盖都是有限范围，模拟可以验证自己边界但不能证明供应商安全。

**易错点 / 踩坑点：**蓝队说继续就默认覆盖第三方；用模拟结果报告第三方已通过测试。

**评分依据（15 分）：**停测归属 3 分；独立许可 3 分；低影响替代 3 分；限定报告及风险 3 分；清理与后续 3 分。 等价且符合情境的防御方案可得分；仅罗列产品、没有解释作用位置不计对应分。

### 8. 重大事故后风险接受（场景题，15 分）

**正确答案 / 参考要点：**

1. 核对事故根因、影响与控制改进证据，不从“已经发生过”推出未来概率下降，识别相同入口及相关依赖。
2. 重新评估剩余风险、不确定性、业务连续性和合规要求，区分不可豁免要求与可由有权主体决定的例外。
3. 比较临时减缓、迁移、停用和转移选项，写清成本、延迟、后果和验证方案。
4. 如接受，记录有权责任人、理由、有效期、补偿控制、触发升级与复查条件；不能无期限遗忘。
5. 验证备份、检测和恢复能力，跟踪迁移里程碑，控制变化或新证据出现时重新决策并留存记录。

**解析：**事故提供新的风险证据，不构成“下次不会发生”的概率规律。接受也不能自动豁免法定或合同要求。

**易错点 / 踩坑点：**用赌徒谬误降低评分；由技术工具作永久业务风险决定。

**评分依据（15 分）：**证据与概率纠偏 3 分；剩余风险及要求 3 分；比较选项 3 分；有限接受 3 分；验证复查 3 分。 等价且符合情境的防御方案可得分；仅罗列产品、没有解释作用位置不计对应分。
