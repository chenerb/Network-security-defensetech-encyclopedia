# 第五章 · 原创防御挑战卷（题目）

> **原创说明**：本卷为本项目原创练习，模拟课程考核与安全岗位追问，不声称改编自具体高校或公司的真实试题。仅用于教育学习和授权防御。

共 8 道主问题，满分 100 分。选择题为单选；简答和场景允许等价防御方案，但须说明边界、步骤与验证证据。

### 1. 不互信租户使用容器，架构评审最关键的问题是哪项？

**题型**：选择题；**分值**：10 分。

- **A.** 镜像大小最小即可
- **B.** 容器名是否随机
- **C.** 所有进程都能访问同一管理套接字
- **D.** 共享内核风险与权限通道是否可接受并受约束

### 2. 服务用 Rust，但 FFI 返回借用指针的实际存活期比声明短。优先整改是？

**题型**：选择题；**分值**：10 分。

- **A.** 以 Rust 名称作为安全证据
- **B.** 核验原生契约并修正所有权和生命周期，增加回归与隔离
- **C.** 关闭编译告警
- **D.** 只启用 HTTPS

### 3. 只读容器可访问数据库凭据和网络出口，能否保证数据不外泄？

**题型**：选择题；**分值**：10 分。

- **A.** 不能，只读限制写文件，不限制读取和网络发送
- **B.** 能，因为不能写磁盘
- **C.** 能，因为文件名受命名空间隔离
- **D.** 只有 CPU 无限才会外泄

### 4. 规则评估比较前后指标，哪个实验设计最可信？

**题型**：选择题；**分值**：10 分。

- **A.** 前组只采集办公终端，后组只采集服务器
- **B.** 把漏采主机从分母删掉
- **C.** 同一标签粒度与代表性留出窗口，同时报告采集缺失和响应时延
- **D.** 只统计告警减少数量

### 5. 场景：文件服务进程只获低权限，MAC 允许访问用户上传目录，但目录中存在指向敏感区的文件引用。设计防御验证，不提供利用步骤。

**题型**：场景分析题；**分值**：15 分。

### 6. 场景：同一窗口按独立事件去重，EDR 评估中 40 次已标记事件，检测到 32 次；共 160 次告警，其中另外 8 次后来确认为独立真实事件，但最初事件集漏标。如何更新指标并防止评估偏差？

**题型**：场景分析题；**分值**：15 分。

### 7. 场景：恶意软件分析虚拟机不接入生产网，却共享宿主剪贴板、文件夹，并登录个人云盘。评价“已隔离”的说法并整改。

**题型**：场景分析题；**分值**：15 分。

### 8. 场景：遗留解析器无法立即迁移，业务要求低时延。设计可复核的三个月风险降低路线图。

**题型**：场景分析题；**分值**：15 分。
