# 操作系统安全机制 · 节末小测（题目）

> **原创说明**：本卷为本项目原创练习，模拟课程考核与安全岗位追问，不声称改编自具体高校或公司的真实试题。仅用于教育学习和授权防御。

共 8 道主问题，满分 100 分。选择题为单选；简答和场景允许等价防御方案，但须说明边界、步骤与验证证据。

### 1. 普通进程为什么不能直接修改内核的访问控制状态？

**题型**：选择题；**分值**：6 分。

- **A.** 名字不同
- **B.** 硬件特权分层和内核检查限制操作
- **C.** 使用了 HTTPS
- **D.** 文件名被隐藏

### 2. 服务有文件读取权限，却被 SELinux 拒绝。合理解释是？

**题型**：选择题；**分值**：6 分。

- **A.** 系统必定损坏
- **B.** 审计系统禁止了一切
- **C.** DAC 允许，但 MAC 策略不允许
- **D.** 管理员账号不存在

### 3. 文件转换服务只需读输入和写结果，最合适的身份是？

**题型**：选择题；**分值**：6 分。

- **A.** 独立低权限服务账号
- **B.** 共享系统管理员
- **C.** 所有服务共用 root
- **D.** 登录用户的全部权限

### 4. 可信启动最直接提供哪种保护？

**题型**：选择题；**分值**：6 分。

- **A.** 证明所有软件没有缺陷
- **B.** 阻止所有账号失窃
- **C.** 加密全部业务数据
- **D.** 验证启动组件满足签名和策略要求

### 5. 哪份日志更适合调查关键文件访问？

**题型**：选择题；**分值**：6 分。

- **A.** 只记访问次数
- **B.** 记录受控身份、时间、对象、结果和关联标识
- **C.** 保存所有口令
- **D.** 让服务自己随意删改日志

### 6. 用生活例子区分访问控制与审计，并解释二者为何都需要。

**题型**：简答题；**分值**：15 分。

### 7. 补丁可能影响业务，如何安排发布而不无限延期？

**题型**：简答题；**分值**：15 分。

### 8. 场景：文档服务被低权限账号运行，但能读取工资目录，日志也存于可写工作目录。设计整改与验收。

**题型**：场景分析题；**分值**：40 分。
