# 第五章 · 原创安全岗压力面（题目）

> **原创说明**：本卷为本项目原创练习，模拟课程考核与安全岗位追问，不声称改编自具体高校或公司的真实试题。仅用于教育学习和授权防御。

共 10 道主问题，满分 100 分。选择题为单选；简答和场景允许等价防御方案，但须说明边界、步骤与验证证据。

### 1. 面试官：服务以 root 运行三年没出事，降低权限只会增加故障，你为什么还要做？

**题型**：压力面试题；**分值**：10 分。

**继续追问**：某个合法操作必须提权怎么办？

### 2. 面试官：ASLR、NX、CFI 都开了，为什么还要投入内存安全迁移？

**题型**：压力面试题；**分值**：10 分。

**继续追问**：性能不能下降怎么办？

### 3. 面试官：容器和虚拟机都在同一物理机上，隔离不都一样吗？

**题型**：压力面试题；**分值**：10 分。

**继续追问**：虚拟机能保证样本无法影响宿主吗？

### 4. 面试官：EDR 告警减少 80%，你能向负责人证明防御改进了吗？

**题型**：压力面试题；**分值**：10 分。

**继续追问**：没有完整真值怎么报告召回率？

### 5. 面试官：样本有大厂签名，为什么还隔离？

**题型**：压力面试题；**分值**：10 分。

**继续追问**：公开平台可快速得到报告，为什么不用？

### 6. 面试官：MAC 拒绝日志太多，直接关掉不是最有效的可用性修复吗？

**题型**：压力面试题；**分值**：10 分。

**继续追问**：生产现在必须恢复？

### 7. 面试官：我们每天自动快照，勒索发生后还需要独立备份吗？

**题型**：压力面试题；**分值**：10 分。

**继续追问**：恢复快照后数据外传是否撤销？

### 8. 面试官：恶意文件已经删除，你还要求重建服务器，会不会过度？

**题型**：压力面试题；**分值**：10 分。

**继续追问**：业务没法立即重建？

### 9. 面试官：服务只读根文件系统，为什么还要限制网络和内存？

**题型**：压力面试题；**分值**：10 分。

**继续追问**：服务需要调用外部 API 呢？

### 10. 面试官：补丁与安全策略上线后故障是谁负责，怎样证明投入值得？

**题型**：压力面试题；**分值**：10 分。

**继续追问**：业务要求永久延期？
