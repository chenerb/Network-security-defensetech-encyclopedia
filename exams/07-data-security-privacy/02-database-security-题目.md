# 数据库安全与脱敏 · 节末小测（题目）

> **原创说明**：本卷为本项目原创练习，模拟课程考核与安全岗位追问，不声称改编自具体高校或公司的真实试题。仅用于教育学习和授权防御。

共 8 道主问题，满分 100 分。选择题为单选；简答和场景允许等价防御方案，但须说明边界、步骤与验证证据。

### 1. TDE 最直接保护什么？

**题型**：选择题；**分值**：6 分。

- **A.** 任何管理员查询
- **B.** 全部网络请求来源
- **C.** 磁盘等静态数据被直接读取的风险
- **D.** 用户真实意图

### 2. 动态脱敏与静态脱敏主要区别是？

**题型**：选择题；**分值**：6 分。

- **A.** 前者通常改变返回展示，后者生成另一个经过处理的数据集
- **B.** 两者都会删除底层数据
- **C.** 前者一定不可绕过
- **D.** 后者一定完全匿名

### 3. 把姓名换成编号，保留可恢复映射，合理称呼是？

**题型**：选择题；**分值**：6 分。

- **A.** 完全匿名
- **B.** 假名化，映射需独立保护
- **C.** 安全删除
- **D.** 差分隐私

### 4. 测试环境数据最合理的优先选择是？

**题型**：选择题；**分值**：6 分。

- **A.** 完整生产库，开放所有人
- **B.** 只删除姓名
- **C.** 客服脱敏界面截图即可
- **D.** 满足测试目的的合成或经过风险评估的静态脱敏数据

### 5. 数据库行级策略已启用，仍需要核验什么？

**题型**：选择题；**分值**：6 分。

- **A.** 只看开关状态
- **B.** 无需应用授权
- **C.** 实际角色、管理员例外、连接池上下文与跨租户拒绝
- **D.** 把所有用户改为管理员

### 6. 为什么精确生日、地区和罕见诊断可能重识别个人？

**题型**：简答题；**分值**：15 分。

### 7. 字段级加密相比 TDE 有什么收益与代价？

**题型**：简答题；**分值**：15 分。

### 8. 场景：客服界面号码有星号，但客服共享数据库管理员账号可导出全表。如何修复和证明有效？

**题型**：场景分析题；**分值**：40 分。
