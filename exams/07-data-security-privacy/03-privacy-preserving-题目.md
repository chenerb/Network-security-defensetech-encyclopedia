# 隐私保护技术 · 节末小测（题目）

> **原创说明**：本卷为本项目原创练习，模拟课程考核与安全岗位追问，不声称改编自具体高校或公司的真实试题。仅用于教育学习和授权防御。

共 8 道主问题，满分 100 分。选择题为单选；简答和场景允许等价防御方案，但须说明边界、步骤与验证证据。

### 1. 差分隐私比较的相邻数据集，应首先说明什么？

**题型**：选择题；**分值**：6 分。

- **A.** Excel 文件名
- **B.** 使用者电脑品牌
- **C.** 统计图颜色
- **D.** 受保护单位以及增加或删除该单位的定义

### 2. ε 的合理解释是？

**题型**：选择题；**分值**：6 分。

- **A.** 隐私泄漏百分比
- **B.** 控制输出分布可区分程度，通常越小约束越强
- **C.** 数据必须加密的字节数
- **D.** 永远越大越安全

### 3. 同一群体连续发布三次，各满足 (0.2, 10^-6)-DP，基本顺序组合上界是？

**题型**：选择题；**分值**：6 分。

- **A.** (0.6, 3×10^-6)
- **B.** (0.2, 10^-6)
- **C.** (0, 0)
- **D.** (0.2%, 3%)

### 4. 哪个操作通常不增加已发布 DP 结果的隐私预算？

**题型**：选择题；**分值**：6 分。

- **A.** 再访问原始数据补数
- **B.** 把未保护明细加入报告
- **C.** 只基于已发布 DP 结果绘制图表
- **D.** 无限次新查询同一人

### 5. 联邦学习不集中原始数据，所以？

**题型**：选择题；**分值**：6 分。

- **A.** 绝不泄漏个人信息
- **B.** 无需认证参与方
- **C.** 更新都可以公开
- **D.** 仍需考虑更新泄漏、安全聚合、访问控制或 DP

### 6. k-匿名为什么不能提供与差分隐私相同的保证？

**题型**：简答题；**分值**：15 分。

### 7. MPC 或同态加密为何仍需评估公开结果？

**题型**：简答题；**分值**：15 分。
