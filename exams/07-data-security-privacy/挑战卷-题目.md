# 第七章 · 原创隐私防御挑战卷（题目）

> **原创说明**：本卷为本项目原创练习，模拟课程考核与安全岗位追问，不声称改编自具体高校或公司的真实试题。仅用于教育学习和授权防御。

共 8 道主问题，满分 100 分。选择题为单选；简答和场景允许等价防御方案，但须说明边界、步骤与验证证据。

### 1. 记录级机制每次满足 ε=0.2，一个用户最多有 10 条记录，可直接宣称用户级 ε=0.2 吗？

**题型**：选择题；**分值**：10 分。

- **A.** 可以，因为用户姓名被隐藏
- **B.** 不能；保护单位不同，需约束贡献并按适用机制分析
- **C.** 只要数据加密就可以
- **D.** ε 是 20% 所以无所谓

### 2. 两个部门分别处理完全不重叠的用户集合，各机制满足纯 ε-DP，输出合并后适用并行组合时基本 ε 是？

**题型**：选择题；**分值**：10 分。

- **A.** 两者 ε 的乘积
- **B.** 必定为零
- **C.** 两者 ε 的最大值
- **D.** 任何数字都一样

### 3. 发布 DP 输出后，追加一个未保护的小群体原始计数，可否整体称为纯后处理？

**题型**：选择题；**分值**：10 分。

- **A.** 不能，追加信息再次访问或披露原始数据
- **B.** 能，只要图表在同页
- **C.** 能，只要用户不知道
- **D.** 只有 PDF 格式才不能

### 4. 多个准标识符都单独很常见，为什么组合仍要评估？

**题型**：选择题；**分值**：10 分。

- **A.** 常见字段永远无风险
- **B.** 列数少就一定安全
- **C.** 不含姓名即结束
- **D.** 联合组合可能稀有或唯一，并可匹配辅助信息

### 5. 推导场景：计数查询保护“增删一个人”，每人贡献最多一票；若可贡献最多五票，如何影响敏感度和设计？

**题型**：场景分析题；**分值**：15 分。

### 6. 组合场景：同一用户集合发布三项纯 DP 输出，ε 分别 0.3、0.4、0.2；再把它们画图；最后新查原始数据发布 ε=0.5 的结果。基本总预算是多少？

**题型**：场景分析题；**分值**：15 分。

### 7. 场景：研究者只可读取动态脱敏视图，但多次细粒度筛选能获得罕见诊断属性，管理员称“看不到姓名就合规”。如何评估并防御？

**题型**：场景分析题；**分值**：15 分。

### 8. 场景：删除机制把用户从主库和索引清除，但 DP 统计已公开，模型训练副本仍存在。分别说明处置原则与不能做出的承诺。

**题型**：场景分析题；**分值**：15 分。
