## 逐题解析

### 1. 状态检测（8分）

**题意与考点**：有状态防火墙跟踪连接主要帮助什么？

考点：Stateful。

**正确答案**：B。

**各选项解析**：

- A（错误）：识别所有业务越权。连接状态不理解全部应用权限。
- B（正确）：按授权连接状态处理相应返回流量。减少无关流量，但还需正确协议和策略实现。
- C（错误）：自动验证用户MFA。网络连接状态不能代替身份认证。
- D（错误）：让NAT成为数字签名。概念无关。

**评分**：选对得8分；错选、不选不得分。

**易错点 / 踩坑点**：把连接是否成立等同于业务是否允许。

### 2. VLAN隔离（8分）

**题意与考点**：两VLAN之间存在不受控路由，正确结论是什么？

考点：分区执行。

**正确答案**：A。

**各选项解析**：

- A（正确）：广播域划分并未形成充分跨区安全边界。需要在连接路径执行明确访问控制。
- B（错误）：有VLAN编号就禁止全部访问。路由可能仍允许跨区连接。
- C（错误）：VLAN自动检查对象归属。二层划分不完成应用授权。
- D（错误）：应取消所有安全规则。会进一步扩大可达范围。

**评分**：选对得8分；错选、不选不得分。

**易错点 / 踩坑点**：把拓扑标签当作实际执行的拒绝策略。

### 3. NAT（8分）

**题意与考点**：关于NAT与防火墙，哪项最准确？

考点：机制辨析。

**正确答案**：D。

**各选项解析**：

- A（错误）：NAT总能阻止所有入站。端口映射、路径和策略会改变可达性。
- B（错误）：NAT提供应用身份验证。地址转换不认证用户。
- C（错误）：NAT自动覆盖IPv6所有路径。IPv6可能使用独立地址和策略。
- D（正确）：地址转换不能替代明确访问策略。应管理入站、出站及跨区规则并检查实际路径。

**评分**：选对得8分；错选、不选不得分。

**易错点 / 踩坑点**：把地址隐藏当作完整安全策略。

### 4. 临时例外（8分）

**题意与考点**：紧急开放一条较宽规则，应怎样管理？

考点：规则生命周期。

**正确答案**：C。

**各选项解析**：

- A（错误）：不记原因以方便操作。缺少审计与责任归属。
- B（错误）：永远保留防止忘记需求。会固化过宽权限。
- C（正确）：记录用途、责任人、期限与回滚并验证。在满足需求同时限制持续暴露，后续复核删除。
- D（错误）：只增加一条相同规则。重复不减少风险。

**评分**：选对得8分；错选、不选不得分。

**易错点 / 踩坑点**：把临时开放看作无需治理的日常操作。

### 5. 默认拒绝（8分）

**题意与考点**：默认拒绝策略上线前，最应做什么？

考点：依赖识别。

**正确答案**：B。

**各选项解析**：

- A（错误）：拒绝DNS、时间同步和所有更新。可能破坏正常业务，引发随意放宽策略。
- B（正确）：盘点必要依赖并逐项有目的放行。既保护边界，也使正常业务具有明确路径。
- C（错误）：直接允许全部内网。网络位置不是统一信任依据。
- D（错误）：只验证主页能打开。无法覆盖数据库、管理、备份与罕见任务。

**评分**：选对得8分；错选、不选不得分。

**易错点 / 踩坑点**：忽略必要公共服务后用万能规则救火。

### 6. 规则字段（15分）

**题意与考点**：为一条“应用访问数据库”规则列出必须可审查的信息。

考点：可审查策略。

**参考答案与防御思路**：

1. 明确源应用身份或受控地址、目标数据库、协议与端口，并限定业务目的而非整个内网。
2. 记录所有者、审批依据、环境、有效期及相关依赖，说明入站与返回流量处理。
3. 给出允许与拒绝测试、日志与变更回滚证据，并复核IPv6、主机及云执行点是否一致。

**评分要点**：按上述3项分别给5、5、5分；每项需要说清机制或可检验证据，部分正确可酌情给分。

**易错点 / 踩坑点**：只写一个端口号，没有来源目标、业务依据和生命周期。

### 7. 允许连接仍有风险（15分）

**题意与考点**：为什么防火墙允许HTTPS不代表所有HTTPS请求都安全？

考点：网络与应用边界。

**参考答案与防御思路**：

1. 防火墙允许连接表达的是网络可达性，端口443并不定义具体业务操作许可。
2. TLS可能使网络设备无法检查全部载荷，合法连接中也可能发生越权或输入处理问题。
3. 后端仍要做认证、对象授权、输入验证和审计；IDS、终端与应用日志补充检测。

**评分要点**：按上述3项分别给5、5、5分；每项需要说清机制或可检验证据，部分正确可酌情给分。

**易错点 / 踩坑点**：认为端口名称或加密协议能替代应用防御。

### 8. 备份区过宽（30分）

**题意与考点**：备份服务器与办公电脑同网段，任意终端可连接管理端口；团队只安装公网防火墙。设计分区与验收。

考点：管理/备份隔离。

**参考答案与防御思路**：

1. 盘点备份写入、读取、恢复和管理依赖，区分业务备份通道与管理员控制面。
2. 把备份与管理资源放入受控区域，只允许指定备份工作负载与受管运维入口访问必要端口。
3. 限制普通终端到备份管理面的可达性，并在应用端设置独立最小权限，保护不可变或隔离副本。
4. 治理出站、IPv6、云和主机路径，灰度上线、保留受控恢复与回滚，给临时恢复规则设置到期。
5. 验收正常备份及恢复成功、办公终端管理连接被拒、异常规则变更可告警，复核长期例外。

**评分要点**：按上述5项分别给6、6、6、6、6分；每项需要说清机制或可检验证据，部分正确可酌情给分。

**易错点 / 踩坑点**：只隔离公网入口，却不约束已处于内网的终端。
